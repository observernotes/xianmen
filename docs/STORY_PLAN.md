## 0. 一页纸

**这个故事讲什么。** 一个被踢下山、被退婚的废柴，捡到一枚戒指；戒指里的老头三千年前被自己最看重的徒弟从背后捅了一剑，却骂了另一个徒弟三千年。少年一路把自己受的气讨回来，讨着讨着发现：自己讨的每一口气，都是师父那口气的回声——当年踢他下山的那只脚，是那个大徒弟亲口吩咐的。最后他站在那个人面前，发现对方也是个“废柴”。**他怎么对这个人，就是他成了一个什么样的人。**

**三条原则。**

1. **选择要有回声。** 八个抉择点，每个都在后面至少三场戏里被人提起、换一个人出场或换一种结局。回声出现时，对话框角上亮一个“回响”小标（`ART.icon('echo')`），旁边一行小字说明是哪次选择（“因为：当年你把休书收回了袖中”）。
2. **深度不加复杂度。** 全部分支只靠 **12 个故事标志位**驱动（§2.3），其中 5 个是现成的。每场戏最多读 2 个标志位；没有“三个标志位的组合才出现”的戏。
3. **守节奏。** 对话场景是“大事”：在外不打断、回洞府再播；一季最多一场；每章阻塞场景 ≤ 8 场；长戏（L）每章 ≤ 2 场；任何场景都能一键跳过，跳过时给一句梗概，**抉择永远不会被跳掉**。

**数量。**

| 项 | 现在 | 方案 |
|---|---|---|
| 主线场景（对话式） | 0（主线 18 段全是两三句的弹窗） | 改写 18 + 新增 44 = 62 场 |
| 人物 / 宿敌戏 | 弹窗若干 | 新增 45 场 |
| 关键抉择 | 0（flag 置了没人读） | 8 个，12 个标志位 |
| 结局 | 5（可叠加，差别只有一句评语） | 8 个主结局 + 坐化，各有过场；后日谈 12 类卡片 |
| 高光过场 | 10 段 | + 23 段（含分支与结局变体共 38 个版本） |
| 台词量 | 主线约 3 千字 | 主线约 3.2 万字、人物线约 1.8 万字（按 §4 的长度级别估） |

## 1. 剧情骨架：九章与节拍

### 1.1 章节主线目标（不含境界）

主线目标只写“做成一件事”。每章的目标里都有一场要打的仗（约战、击败宿敌、守山、阵前、问剑、天劫），战力门槛由那一仗把着，所以不需要再写境界。没入宗的玩法（散修丹师出身、天道试炼“无宗”、抉择二选了散修）走“无宗”一栏。

| 章 | 名 | 主线目标 `main.c` | 无宗时 | 高潮场景 |
|---|---|---|---|---|
| 一 | 废柴 | 赢下三年之约（输了：论道击败约战对手） | 同 | 约战 → 抉择一 |
| 二 | 入世 | 晋升内门，并进天骄榜前 60 | 天骄榜前 60，并击败 2 个首领 | 抉择二（入哪条路）、入宗第一天 |
| 三 | 旧怨 | 晋升真传，并击败赵乾 | 击败赵乾，并击败 3 个首领 | 赵乾落败 |
| 四 | 立名 | 成为圣子 / 圣女 | 天骄榜前 20，并击败 4 个首领 | 圣子之战；抉择三（苏与夜）在本章开放 |
| 五 | 问剑 | 击败楚天阔，并在九宗会武压过天剑宗 | 击败楚天阔，并击败 5 个首领 | 楚天阔落败 → 抉择四（他的去路） |
| 六 | 守山 | 击退来犯的天剑宗 | 同（来犯的是你的洞府与落霞城） | 守山 |
| 七 | 真相 | 得知三千年前的真相（`st_truth`），并了结正魔大战（`war_done`） | 同 | 抉择五（怎么恨）、抉择六（站哪边） |
| 八 | 了断 | 登上天骄榜前二，问剑天剑宗，了断陆天衡（任一 `tianheng_*`） | 同 | 抉择七（面对陆天衡） |
| 九 | 飞升 | 渡过九九天劫，并在天门前作出选择（任一 `asc_*`） | 同 | 抉择八（天门） |

改动说明：

- 第七章原目标“击败血无涯”并进正魔大战：先在论道上击败血无涯（这是本章的战力门槛，打过他，两军才都拿你当回事），阵前那场戏才开；站正道时阵前的对手还是他，站魔道时换成正道盟军的先锋（太虚剑宗剑十三），止战要连接双方各一招。阵前的对决输了：养伤，六个月后两军再对阵一次。“击败血无涯”另留一条札记。
- 第八章原目标“成为宗主并带宗门登顶”降为本章札记任务（奖励照旧），同时是结局“掌宗飞升”的条件。原因：了断陆天衡才是全剧的高潮，不该被“攒贡献”挡住。本章的战力门槛换成“天骄榜前二”——问一宗之主的剑，头上只能剩云无极一个人。
- 第九章的主线是“渡过九九天劫，并在天门前作出选择”；“击败云无极”是本章札记（称号「天下第一」），也是“问天”的线索之一。
- 无宗一栏沿用章节进度那条线定的“散修之路”（`L.loneRoute` / `L.LONE`：天道试炼“无宗”、散修丹师不入宗）；抉择二选了“哪家也不去”（`path_san`）且之后一直没入宗的，也走这一栏。
- 第二～四章仍挂着宗门身份（内门 / 真传 / 圣子）。身份晋升自己有境界门槛，那是宗门系统的规则，不是主线写的条件；无宗一栏完全不看身份。

### 1.2 节拍：一章怎么排戏

每章固定七个节拍位，由串联层（`src/logic/story.js` 的 `L.STORY_BEATS`）按顺序放出，场景用触发键 `sb:<节拍 id>` 挂上去：

| 节拍 | 什么时候放 | 作用 |
|---|---|---|
| `open` 开章 | 进入本章后第一次在洞府空下来 | 立本章的冲突；上一章的余波一句带过（章与章的过渡就写在这里） |
| `mid1`～`mid3` 中段 | 距上一场 ≥ 6 个月，且本章主线进度过了 20% / 45% / 70%（进度卡住时，距上一场 ≥ 24 个月也放） | 人物戏；回声在这里出现 |
| `pre` 高潮前 | 主线只差最后一仗（或进度 ≥ 85%） | 把赌注说清楚 |
| `climax` 高潮 | 最后一仗打完（`beat:*`、守山、阵前、问剑、天劫） | 抉择落在这里 |
| `end` 章末 | 主线完成，章末结算卡之前 | 收一句，留一个钩子 |

规则：

- **只在洞府播**，在外（历练 / 闭关 / 秘境）触发的进队列，回来第一次空下来时播（沿用 `st.storyQ` 与 KAIRO §3.3 的排队）。
- 同一季（3 个月）最多一场；高潮与章末两场可以连播（中间隔着战斗或结算卡）。
- 节拍按表里的顺序一个一个放；玩家越过了某个节拍的条件（比如一口气把两章主线打完），没放的中段戏记为“错过”（以后在【仙途 → 记录 → 回忆】里补看，不给选项、按默认分支——这一项留给 D 线）。**每章的开章（主线剧情）和带抉择的场景永远补播，不会错过**（一个月补一场）。
- 开头的上手引导没走完时不放戏；有解锁卡等着时，解锁卡先出。
- 放过的节拍、场景却没结算（队列被清、对决输了要重来），每月补进队列一次。
- 系统剧情不占节拍：`story_sect`（入宗）、`story_pet`、`story_trib1`、三段心魔劫 `story_demon1～3`、`story_boss5`（首杀剑冢）、`story_daolv`、`story_rank12` 仍按各自的系统触发键（`sect`、`trib:1`、`demon:N`、`boss:5`……）。心魔劫跟着突破走，这是突破系统的戏，不是主线进度。

### 1.3 九章

每章列：戏剧目标 / 冲突 / 转折 / 高潮 / 与下一章的过渡，以及节拍上挂的场景（详表在 §4）。

**第一章 废柴** —— 屈辱，和第一口气。

- 冲突：全城等着看笑话；老祖嫌你笨，却一句别人的坏话都听不得。
- 转折：约战前夜，老祖头一回不骂人，问“赢了以后想干什么”。
- 高潮：三年之约。赢了以后休书在你手里——**抉择一**。
- 节拍：`open` s1_night 破庙第一夜 → `mid1` s1_town 落霞城的闲话 → `mid2` s1_firstblood 头一回见血 → `mid3` s1_letter 没署名的信 → `pre` story_pact_eve 约战前夜 → `climax` s1_pact_after（赢）/ s1_pact_lost（输）→ `end` 并入第二章开章。
- 过渡：约战那一剑用的是老祖借的力。回破庙的路上，五色灵根自己转了起来。

**第二章 入世** —— 从一个人，到有处可去。

- 冲突：三宗抢的是“打了慕容家脸的那个人”，不是你；魔门也递了帖子；老祖只有一条：谁都行，天剑宗的盟友不行。
- 转折：混沌初醒，老祖声音发颤，夜里说梦话。
- 高潮：**抉择二**——接哪张帖子，或者谁的都不接。
- 节拍：`open` story_r1 混沌初醒 → `mid1` s2_invite 三张帖子 → `mid2` story_sect 入宗第一天 / s2_alone 没有山门的人 → `mid3` s2_firstfriend 头一个朋友 → `pre` s2_zhao 还是那只脚 → `climax` s2_rank 榜上有名 → `end` s2_end 两个徒弟。
- 过渡：赵乾放下一句话——“金丹论道，我在台上等你。”

**第三章 旧怨** —— 把旧账讨回来，才发现账后面还有账。

- 冲突：赵乾；深夜来夺戒的墨家人说“你不知道里面关着什么”。
- 转折：你第一次怀疑老祖。
- 高潮：赵乾落败，吐出一句：“那一脚，是宗主亲口吩咐的。”
- 节拍：`open` story_r2 夜半黑衣 → `mid1` s3_ring_doubt 里面关着什么 → `mid2` mo_1 墨色剑帖 → `mid3` s3_zhao_eve 论道前夜 → `climax` s3_zhao_fall 那一脚的来历（含放 / 押 / 逼问）→ `end` s3_end 没渡完的劫。
- 过渡：天剑宗的宗主，为什么要亲自过问一个外门杂灵根？

**第四章 立名** —— 从被人挑，到被人争；有人开始等你回家。

- 冲突：圣子之争；苏与夜各自的难处把你往两边拉。
- 转折：天剑宗长老上门示威，老祖随口补全了剑诀——“只偷了上半句。”
- 高潮：圣子之战。**抉择三**（苏 / 夜 / 谁也不耽误）从本章起可以发生。
- 节拍：`open` story_r3 残缺的剑诀 → `mid1` s4_two_lamps 两盏灯 → `mid2` s4_tiankuo 第十式 → `pre` sect_succession 三处灯火 / s4_challenge 落霞城立擂 → `climax` s4_heir 圣子 → `end` s4_end 柴房的管事。
- 过渡：楚天阔走的时候说：“你那一式收势，是我宗的，又不是。会武上，我要再看一遍。”

**第五章 问剑** —— 剑指天剑宗的年轻一代，旧案第一次露出轮廓。

- 冲突：楚天阔骄傲，但不脏；他越正直，越衬出他师门的事不对。
- 转折：半块玉简——“问师祖，可曾信过墨离？”老祖暴怒。
- 高潮：楚天阔落败，回去查碑，被逐出门墙——**抉择四**：留他、给他指条路、劝他回去认错。

**第六章 守山** —— 别人打上门来，你才发现自己有了要守的东西。

- 冲突：天剑宗以“交出邪戒”为名压境；自己人里有人想把你交出去。
- 转折：祖师画像上的人——“陆、天、衡。本座的好大徒弟。”

**第七章 真相** —— 知道一切，然后决定怎么恨。

- 冲突：真相和老祖三千年的恨对不上；陆天衡借“正魔大战”把九宗绑上战车，要在乱军里把你和戒指一起抹掉。

**第八章 了断** —— 给三千年前的事一个结局。

- 冲突：陆天衡不是怪物，是另一个被当成废柴的人。
- 转折：他跪在碑前只问一句：“他后悔收我吗？”
- 高潮：**抉择七**——杀、废、昭告天下、放。

**第九章 飞升** —— 出师。

## 6. 对话场景：播放器规格与数据格式

### 6.1 三种呈现的分工

| 呈现 | 用在哪 | 长度 | 谁来播 |
|---|---|---|---|
| **事件弹窗**（现有 `showChoice`） | 随机访客、途中遭遇、秘境、坊市、宗门日常——一段话 + 选项 | 1 屏 | `src/ui/events.js` |
| **对话场景**（新） | 主线节拍、人物戏、宿敌戏——有来有往的台词，可带抉择 | 6～40 句 | 新 `src/ui/talk.js` |
| **高光过场**（现有 `cine2`） | 一句台词顶一场戏的时刻——画面为主，字幕 ≤ 12 字，不带选项 | 6～25 秒 | `src/ui/cine2.js` |

三者可以串：过场 →（黑一下）→ 对话场景 → 抉择 → 过场（分支版本）→ 结算卡。写法是在场景上写 `cine`（开场前播）和选项结果上写 `cine`（选完后播）。

### 6.2 对话场景的画面（手机竖屏）

```
┌──────────────────────────┐
│ 回看                跳过 ▸▸ │  顶条：黑底。左【回看】本场已说过的话；右【跳过】
├──────────────────────────┤
│                          │
│     场景底图 200×120       │  ART.storyBg(kind) / storyCg，整数倍放大，和过场同一套取景
│   ┌────┐        ┌────┐   │
│   │主角 │        │对方 │   │  半身像 48×48 放大 3 倍，站在底图下沿；主角在左，对方在右
│   └────┘        └────┘   │  正在说话的那位亮着、上浮 2 像素；另一位压暗 45%
├──────────────────────────┤
│ ▍老祖                     │  名牌 ART.frame('talkName')；主角用 'talkNameMe'
│ ┌──────────────────────┐ │
│ │ 笨。本座看着都替剑委屈。 │ │  对话框 ART.frame('talk')：两行，每行约 18 字；逐字出（每字 28ms）
│ │ ……手腕再沉半寸。     ▼ │ │  右下角 ART.talkNext 两帧跳动 = 可以点了
│ └──────────────────────┘ │
│  ◎ 因为：当年你把休书收回了袖中 │  回响小标（有才显示）：ART.icon('echo') + 一行小字
│     点一下继续 · 长按快进     │
└──────────────────────────┘
```

- **点一下**：字没出完 → 立刻出完；出完了 → 下一句。**长按 0.4 秒**：快进（每句停 120ms 自动翻），松手停。
- **【跳过 ▸▸】**：跳到本场的下一个选项；没有选项就直接结束，并弹一行梗概（场景的 `gist` 字段，≤ 30 字）。**选项不能跳过。**
- **【回看】**：一张上滑的纸，列出本场已经出现的台词（说话人 + 句子）。
- **旁白**（`nar`）：没有名牌，字居中，斜一点的淡色；两个半身像都压暗。
- **表情**：每句可以带表情（五种基础表情 + `ART.portraitX` 的七种叠加）。
- **选项**：对话框换成 2～4 个按钮。关键抉择（`key: 1`）用 `ART.frame('talkPick')`、按钮左上一枚 `ART.icon('branch')`，下面一行小字 `hint`；上一世选过的选项右上有个小点。关键抉择点下去之前**没有二次确认**，但选项出现时会停表 0.6 秒不可点，防止连点误触。
- **结果**：选完接着播结果里的 `talk`（如果有），最后落到现有的结算卡（得了什么、好感 ±、称号），这一张沿用 `showChoice` 的结果页，不重做。
- **声音**：逐字 `SFX.type`（每 3 字一响）；换人 `SFX.tap`；关键抉择出现 `SFX.gong`；回响小标亮起 `SFX.bell`。配乐按场景的 `bgm` 字段（缺省：洞府夜谈 `home`，对峙 `boss`，伤感 `sorrow`，定誓 `vow`）。
- **排队**：对话场景和高光过场同级（KAIRO §3.3“大事”）：在外不播、进 `st.storyQ`；播的时候停表；章末卡、解锁卡让路。自动化测试（`navigator.webdriver`）下默认快放：不出画面，按每个选项的默认项（第一个可选的）走完，`window.__xm_talk.fast = false` 关掉；`window.__xm_talk.pick = { 场景id: 选项序号 }` 指定分支。

### 6.3 数据格式

对话场景就是一条 `where: 'story'` 的事件，多了几个字段。**没有 `talk` 的事件照旧走弹窗**，所以现有 367 条不用动；改写主线时只是给它加 `talk`。

```js
{
  id: 's1_pact_after', where: 'story', trigger: 'sb:c1_climax',   // 节拍触发键
  need: ['beat_mu'], origin: 'qitu',                                // 现有的资格字段照用
  title: '休书', scene: 'dusk', bgm: 'vow',                          // scene：底图；bgm：配乐
  gist: '约战赢了，休书在你手里。',                                   // 跳过时显示的梗概
  cine: 'pact1',                                                    // 开场前先播的过场（可省）
  talk: [
    ['nar', '擂台下三千人，没有一个出声。'],
    ['mu:shock', '……你赢了。'],
    ['elder:joy', '愣着干什么。本座教过你，赢了要说话。'],
    { if: 'mu_letter', echo: '你拆过那封信', say: [['me', '（那封信上的字，和她现在的脸色，对不上。）']] },
    ['me', '……'],
  ],
  choices: [
    { t: '当众念休书', key: 1, hint: '这一句，全城都听得见', dao: 'k',
      ok: { talk: [['me:ang', '“慕容雪，性骄，无德——今日休之。”'], ['mu:sad+tear', '……好。念得好。']],
            cine: 'xiushu_shame', text: '休书传遍了落霞城。', fx: { flag: 'mu_shame', xp: 4 } } },
    { t: '把休书收回袖中', key: 1, hint: '不说话，也是一种话', dao: 'w',
      ok: { talk: [['me', '两清了。'], ['mu:shock', '……你——']], cine: 'xiushu_spare', text: '你转身下了擂台。', fx: { flag: 'mu_spare', xp: 4 } } },
    { t: '问她一句', key: 1, hint: '“当年，是你的意思吗？”', dao: 'r', need: ['mu_letter'],
      ok: { talk: [/* … */], text: '她没有回答。但她没有走。', fx: { flag: ['mu_spare', 'mu_asked'], xp: 4 } } },
  ],
}
```

台词一行的写法：

| 写法 | 意思 |
|---|---|
| `['elder', '……']` | 老祖说，表情默认 `n` |
| `['mu:sad+tear', '……']` | 慕容说，基础表情 `sad`，叠加 `tear`（叠加名见 `ART.portraitFxNames`） |
| `['me', '……']` / `['me:ang', '……']` | 主角 |
| `['nar', '……']` | 旁白 |
| `['?:黑衣人', '……']` / `['mo:n:黑衣人', '……']` | 第三段是显示的名字（没露身份时用）；`?` 开头 = 没有半身像，只有剪影 |
| `{ if: 'flag', say: [...] }` | 有这个标志位才说。`if` 可以是数组（全满足），`'!flag'` 表示没有；也可以是这几种固定写法（`L.storyCond`）：`'path:zheng|mo|san'`、`'daolv:su|ye|none|any'`、`'origin:qitu'`、`'aff:su>=60'`、`'aff:su>=aff:ye'`、`'met:mo'`、`'grudge:xue<=-40'`、`'ch>=3'`、`'pact:win|lost'`、`'trial:wuzong'`、`'gate:stop'`（某个有条件的选项此刻满足）、`'rebirth'`、`'sky'`（上一世问过天）、`'awakens'` |
| `{ if: …, echo: '一句说明', say: [...] }` | 同上，并亮回响小标 |
| `{ pick: [ { if: 'a', say: [...] }, { if: 'b', say: [...] }, { say: [...] } ] }` | 从上往下取第一条满足的（最后一条不写 `if` = 缺省） |
| `{ cg: 'stab', f: 1 }` / `{ scene: 'grave' }` | 换底图（关键画面 / 场景），不占一句 |
| `{ sfx: 'thunder' }` / `{ shake: 4 }` | 音效 / 震屏 |

人物 id 用半身像的 id（`elder mu zhao tian xue yun su ye chu ge bai mo tianheng teaman`、长老与圣子的 id 见 ART_API 阶段三·批次八）；没有半身像的小角色用 `'?:名字'`。

选项上另有：`key: 1` 关键抉择、`hint` 小字、`gate: 'stop' | 'expose' | 'stay' | 'break' | 'kept' | 'xuesha' | 'letter'`（有条件的选项：不满足时灰着，写明缺什么，见 `L.STORY_GATES`）、`cond`（同 `if` 的写法，不满足就不显示）。事件上另有 `chMin` / `chMax`（当前章的上下限，0 起）、`cond`。结果的 `fx` 新增：`join: 'jian'`（拜入宗门）、`retry: 6`（这场戏 6 个月后重来，对决输了用）、`unsect: 1`（被正宗除名）。

规格限制（`tools/check_events.js` 会查）：一句 ≤ 36 字；一场 `talk` + 最长分支 ≤ 40 句；`key: 1` 的选项必须有 `hint`；每场必须有 `gist`（≤ 30 字）；表情与叠加的名字必须认识；老祖的台词里不出现“老夫”。`tools/story_check.js` 查：每个故事标志位至少两处回声、抉择场景齐全、节拍都挂得上、预设路线落在预期的结局。

## 7. 十段样稿

写法说明：下面用“剧本体”，和 §6.3 的数据格式一一对应——`老祖(ang)` = `['elder:ang', …]`，`旁白` = `['nar', …]`，`[若 X｜回响：…]` = `{ if: 'X', echo: '…', say: […] }`，`〔画面 stab 1〕` = `{ cg: 'stab', f: 1 }`。`▶` 是选项，`★` 是关键抉择。写手交稿用数据格式；这里用剧本体是为了好读。样稿里的句子可以直接用。
