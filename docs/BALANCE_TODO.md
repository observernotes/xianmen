# 最终调数值时要处理的事项

各系统开发时记下、留到最后统一校准的问题。

- ~~宿敌从拍卖拿到东西的永久加成没有单人上限~~：宿敌与新秀那一刀已改成每人合计上限 ×1.3（`L.rivalBoost`，拍卖 ×1.04 与宿敌的奇遇 ×1.05 都走它；旧档迁移时压回 ×1.3）。lazy 的宿敌现在一世到 ×1.30（以前 ×1.67），guided 的也常到顶（奇遇每届论道之间 12%）。
- 宿敌时机（DESIGN §3.12 的“击败赵乾 / 楚天阔 / 血无涯”与“天骄榜第一”两行）：宿敌与新秀这一刀之后 guided 48 / 120 / 216、榜一 300（`norivals2` 48 / 108 / 216、300），目标 72～110 / 190～300 / 340～480、510～600。宿敌仍按天骄榜曲线（SYSTEMS §13），只多了上限 ×1.3 的永久系数——差距是曲线本身：guided 的战力在第 90 周天约是第 45 名曲线的 19 倍、第 245 周天约是第 12 名的 150 倍、第 410 周天约是第 4 名的 50 倍、第 555 周天约是第 1 名的 4 倍（`node tools/sim.js guided 1 v 7` 对照 `L.rivalCurve`）。要落进区间，得在最后统一校准时二选一：给每位宿敌一个“卡位”系数（约 ×19 / ×150 / ×50 / ×4）并让没打赢的宿敌挡住名次（论道不能越过他），或把整条 RA 锚点后段拉高、斜率从 0.0185 提到约 0.03（会连带九宗会武的宗门战力）。lazy 的“击败赵乾 ≤ 160”是现在唯一达标的宿敌行（120），卡位系数要按它留余量。
- 新秀（rivals2.js 的 `L.ROOKIE`）：战力 = max(他那一格的曲线, 参照战力 × (0.45 → 0.92～1.06，追三届升满))，参照 = 上届论道时你的战力。guided 打压胜算约 70%（会先换克他的战技）、一世 8 位里赢 4.5 输 2.2；lazy 被曲线压着（他那一格的曲线比 lazy 强），打压胜算只有约 15%、多半指点。打压赢的词条挪到兵器上（兵器最多三条），换兵器时不继承——一世净得约 1～2 条，战力影响很小。指点后送礼：每位每 24 周天 15%、一份 3 周天收入，最多记 4 位（一位约等于收入 +2%）。
- 恩怨 ≥ 60 的人数：guided 一世约 1 人（多半是被羞辱选项推上去的赵乾或云无极），伏击约 3 回；≤ −40 很少（要连着几回“放他一马”）。如果想让化敌为友线更常见，可以把论道上“赢他 +20”降到 +10，或让化敌为友的事件放宽到 −30。
- sim 里仍未达标的行（历法与坊市完成后共 10 行，都不是门槛行）：各境界时长、约战前已筑基、击败宿敌的时间、天骄榜第一的时间、宗门身份晋升时间、突破失败次数、lazy 的三行。天劫与道心因果之后 11 行：多了 guided 飞升周天（558，见下面“道基超预算”）。
- 页面体积：所有美术合并后单文件约 1.48 MB，DESIGN 阶段五的目标是 ≤ 1 MB——发版前看能否压缩（字体子集、art.js 缓存逻辑）。
- longrun 现在约 30 分钟（机器人通过界面逛坊市）。
- 突破失败次数（天劫与道心因果之后）：BT 基础值已整体 −0.10（金丹起），但 guided 把护劫手段全用上、临阵吞丹补到封顶，几乎每次都是 100%——一世失败中位数仍是 0（目标 2～6）；lazy 1（0～3）。要落到 2～6，得在最后统一调：再压 BT、给护劫手段降一档，或让 guided 不再“补满”（SYSTEMS §9 写的是“有就全用”）。
- 道基超预算：guided 成功率常是 100%，评价分布 完美 50% / 上 27% / 中 16% / 下 8%，渡劫期道基 +15%、一世 +18%（§18 预算 +12%）。guided 飞升 606（`nodaoji`）→ 558，掉出 580～660；天骄榜第一 324 → 288。可选：评价门槛跟着成功率走（比如余量按 p 未截断前算）、每档少给一点，或最后把 L.TR 后段拉长。
- 合并灵宠之后 guided 飞升 530（`nodaoji` 574）：灵宠与道基叠在一起比 580～660 快了一截，最后统一校时一起算。
- 因果目前一世中位数 0 条：能记因果的事件多半还闸在秘境、恩怨、人脉后面（EVENT_INTEGRATION 第四刀列了），那几个系统上线后再看寻仇事件（ev_karma.js）的频率与赔礼价钱。
- 合并秘境之后 guided 飞升 514（`norealm` 543）、天骄榜第一 264（`norealm` 312）：秘境单独对照时基本持平（603 → 607），与灵宠名册、天劫道基叠起来快了约 5%。可调的口子在 `src/logic/realm.js` 的 `L.MJ`：`rew`（一间战斗房的灵石，现 0.12 × 家门口腹地历练奖励）、`dropP`（战斗房三成掉宝）、层战力 `recD` / `powStep`（掉血）、秘境令（每夏一枚 + 坊市 `token` 基价 500）。guided 一世约 47 局、几乎不出局；“历练收入 : 被动收入”因为每局出来那 3 个周天降到 0.85（算上秘境的灵石约 1.3）。秘境事件里能记因果的 `realm_altar`、`realm_sword_slave` 已上线。
- 宗门身份（宗门加深之后）：人脉让圣子从 112 推到约 173（只差人脉卡住约 50 周天），但长老 / 太上 / 宗主（183 / 286 / 358）仍是被境界卡着的——化神 / 合体 / 大乘一到就升，那时三位长老的支持早已 80～100。境界节奏拉长到 §3.12 以后再看；要是那时宗主还早，可以让支持随时间回落一点（人走茶凉），或把宗主的门槛改成两位 ≥ 80。可调的数在 sect2.js 的 L.FAV（任务 +3、送礼 +6 只送到 40、入宗 10）。
- 宗门当值（每周天一趟乙等历练贡献的 0.3）与出师（8 趟）让中后期贡献偏多，宝库六格限量兜着；“历练收入 : 被动收入”与灵田炼丹合并后 1.06 → 1.07；guided 传授、讲法各占 2 个周天，飞升 509 → 524。
- 三人会武：对方两名弟子按你的小层 − 16 算（L.TRIO_LV），guided 留下的两个徒弟约赢 4 / 7 场；徒弟成长 0.02 × 灵根 / 周天在 §11 原文里，金丹出师大约要 160～250 周天。
- **见多识广（图鉴，SYSTEMS §15）按投胎时的完成度算**：一世里实时生效时 guided 第一世图鉴完成度约 56%、到后期 +5%，飞升 524 → 506（快 3.4%），三年之约那时 +1%。现在改成 `st.cxBirth`（这一世新记的下一世才算），第一世 +0%。最后校准时可选：实时生效但每 20% +1%，或保持现状。
- **图鉴各类的格数**与 SYSTEMS §15 的写法不完全一样：法宝 77（含首领专属、器方打造、镇宗，§15 写 59）、灵宠 37（12 种 + 麒麟 + 24 形态）、丹方 19（含基础三方与九转秘方）、奇遇散件约 204（按上线事件现算）、秘境 9（四主题各“五层 / 通关” + 混元道经）、人物喜好 14（等送礼系统的 `L.giftKnown`，没接上时这一类不计入完成度）。总完成度是各类比例的平均，大类不会淹没小类；guided 第一世约 56%（地点相性、丹方、秘境、对手属性几乎集齐，奇遇散件约四成）。
- **成组加成**（某一类第一次集齐，`L.CX_GRP`）都挑了不怎么改节奏的：历练分数 +1、寿元 +2～3%、突破 +1～2%、奇遇把握 +1～2%、成丹率 +2%、灵石收入 +2～3%；guided 第一世一般集齐 1 类（秘境），轮回道果 +40。
- **道果**（`L.DG`）：guided 第一世约 2800（其中图鉴新格约 560，DESIGN v1 公式部分约 2000，与 v1 估的 1800～2200 一致）；轮回殿价格照 v1（宿慧 / 根骨 300…2200）加 §16 的五个（800 / 1000 / 400 / 600 / 1500）与出身（500～1000）。全部点满约 2.4 万道果，按现在的产出要七八世。第二世与第一世飞升之比（`node tools/sim.js guided 40 life2`，DESIGN 阶段四验收 0.75～0.90）：只买宿慧一级 0.73、什么都不买 0.82（命格中位天灵根 + 见多识广 +5% + 传承功法）、照 `L.HALL_ORDER` 花光 0.69——偏快。可调：宿慧每级 +15% → +10%（core.js `L.rebCul`）、见多识广每 20% +1%、命格权重（meta.js `L.rebirthCards`），或抬轮回殿价格。
- **出身**（CONTENT §11）只在转世后可选，第一世永远是弃徒（三年之约门槛不动）。转世后的约战没有老祖借力（v1 就这样；“老祖的记性”给 ×1.5），出身给的开局资源（法器、丹炉 2 级、月牙兔、灵石 300…）与约战难度都没校过。CONTENT 里的“烈火刀”“守墓短剑”没有对应底子，先给同阶（法器）的随机兵器；御兽遗脉“自身战力 ×0.9”走 `L.addAtkMod('origin')`。散修丹师“无宗时货架 +2 格”是补货那一刻临时把 `L.SHELF.rot` +2。
- **天道试炼**系数照 v1 与 §16，没校：限时（第 480 周天）对 guided 第一世（中位 506）几乎必死，留给有轮回殿加成的后几世；五行缺一封的是随机一系，碰上主修那一系会很疼。
- **奇遇链**：guided 第一世约走完 3 条、推进 17 步（藏宝图约 95%；天剑宗旧案、卖茶翁、老祖旧剑、东海、星墟各三四成；丹经、墨家、狐族、圣火要那位人物三四心才起头，sim 的随手选项攒不到）。老祖旧剑常卡在第 2 步（剑冢历练途中）——guided 很快就越过上古剑冢，靠“该来了就去那张图”补回一部分。链的终点奖励（寻龙诀、九转、玄霄、沧海无量、鸿蒙残篇…）合起来对节奏影响很小（`nochains` 对照见 README）。
- **九尾天狐**（狐族秘地终点 `fox_blood`）：pets.js 的形态只到 0～2，ART 已有 p_hu 的第 3 形态；现在 bai_end 只给一只雪团灵狐，留给灵宠那边接（迁移里 form 也要放开到 3）。
- 洞府地块、建筑与阵法（200 种子）：guided 飞升 537（`nohome2` 回到地块之前 525）；合并宿敌与新秀后 536（`nohome2` 530），“历练收入 : 被动收入”0.94（`nohome2` 1.13）。三年之约门槛 94% / 17% 不变。和 SYSTEMS §6.1 不一样的两个数：
  静室闭关倍率按“替换原洞府本体的 +0.05/级”取 **+0.05/级**（SYSTEMS 写 +0.08，满级会比原来多 +0.36，guided 约快 5%）；聚宝阁被动灵石取 **+2%/级**（SYSTEMS 写 +6%，满级 +72% 时“历练收入 : 被动收入”1.08 → 0.54，+2.5% 时 0.78，+2% 时 0.87）。
  guided 一世末的洞府：8 块地，聚灵阵 28、灵田 28、丹炉 20、静室 12、聚宝阁 12、藏经阁 10、器炉 15、兽栏 12（灵泉、迎客亭、传送阵挤不进来——迎客亭 2 万起、传送阵 30 万 × 4^级，9 级要 26 亿，一世到不了）；
  前期（筑基 → 元婴）慢一点（洞府本体不再加闭关，静室筑基后期才开、要从 1 级升），后期（大乘、渡劫）快一点（藏经阁熟练 +100%、聚宝阁），合起来飞升慢约 2%；天骄榜第一 300 → 312（器炉要先占一块地才能打造）。
  阵法：guided 一世约 7 张阵图、换阵 16 次，渡劫阵护劫 7 次——guided 本来就能把成功率补到 100%，渡劫阵主要省下临阵吞丹，几乎不影响道基。
  可调的口子：`L.HV`（home.js 每级效果）、`L.ZV`（formation.js 阵法强度）、各建筑 base / grow（CONTENT §7）；手持灵石 / 收入 21.1 → 17.1（建筑是灵石去处），这一行反倒达标了。
- 人物加深（people.js，`nopeople2` 对照，200 种子，已合并奇遇链 / 图鉴 / 轮回）：引导型飞升 534 → 526（快约 1.5%），三年之约 guided 95% / idle 17%（门槛内，guided 贴上沿）。
  拆开量过（同一批种子）：关掉知己加成全部 536、关掉委托 533、关掉同伴 528、不送礼 531——快的那几个周天几乎全来自“送礼与委托让更多人到 60（知己）”，知己数中位 1 → 3，第一位到 60 / 80 的周天 359 / 415 → 259 / 317。
  已做的抵消：道侣常驻 ×1.25 → ×1.1（双修补回来）；知己的修炼 / 战力三项三心给一半、五心给满（`L.FRIEND_PART` = 0.5）。再压到 0（只有五心才给）测下来仍是 526，说明剩下的是分散的：夜的历练灵石 ×1.2、葛老知己的成丹率与洗髓丹门槛、白小九的奇遇 ×1.5、委托奖励（功法、灵矿、丹、墨家遗物）、同伴。
  可调的口子：`L.PGIFT_V`（+8 / +3 / −3，任务书定的）、`L.PQ_AFF`（+15）、`L.PQ` 的奖励、`L.FRIEND_PART`、`L.FRIEND_YE_STONE`（夜的历练灵石也按心数折，测过影响很小）、串门事件 `pp_*_drop` 的冷却（12）。
- 道侣在 sim 里很少（约 4%，中位第 481 周天）：su_5 / ye_5 要先走完 su_crisis → su_bond 这条随机访客链，guided 随手选选项常常走岔。双修（每 12 周天、免费闭关 + 对方功法）几乎没被 sim 量到，`L.SX`、`L.DAOLV_ARTS` 没校过。
