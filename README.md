# 废柴仙途

一款像素风个人修仙游戏。被宗门逐出、被当众退婚的杂灵根废柴，捡到一枚住着老爷爷的戒指，从此一路逆袭到白日飞升。

系统极简、只靠点按，修仙的爽点一个不少：灵根觉醒、三年之约、渡劫突破、越级挑战、三宗争徒、宗门晋升、天骄榜打脸、白日飞升、转世重修。

单文件网页，打开 `dist/index.html` 即可游玩（手机、电脑都行），进度自动保存在本机。

## 怎么玩

第一次进游戏，戒中老祖会像秘书一样一步步带你：一次只说一两句，说话时游戏暂停，每句都带具体数字（“战力 10 → 13，胜算 3% → 16%”），说完立刻让你动手。坊市、宗门这些入口一开始是灰的，用得上时才解锁，老祖会在那一刻告诉你它能干什么。

修为条下面一排是**核心数值**：修炼/周天、战力、灵石/周天，最右边是**下一件大事**的倒计时——开局是“约战 N周天 · 胜算 X%”（三年之约），之后是天骄论道、九宗会武。点前三格能看到数值由哪些加成组成、怎么提升；约战前点最右边能看到双方战力和“老祖锦囊”（每条办法能把胜算提到多少），筑基且约战打完以后点开是**年历**：一条 24 格的时间轴，标着论道、拍卖会、会武、夏季秘境和当前的天下大势，各带倒计时。

一年 12 个周天分四季：春（灵草、惊雷竹、长生藤 +50%，访客多三成）、夏（秘境开放、兽类地图斩妖灵石 +15%，灵谷、赤炎果 +50%）、秋（灵稻的灵石 +50%、行情 +0.2）、冬（闭关倍率 +0.2，冬末论道，寒霜莲、养魂花 +50%）。每年第 2 个周天看一次天象，六成起一件**天下大势**（兽潮、灵气潮汐、丹道大会、矿脉现世、魔劫、流星雨、大旱、仙府现世、商路断绝、名师讲道、通缉令、太平无事），持续 6～10 周天，场景右上角挂一块小牌，老祖开头说一句“这几个周天该干什么”（带数字）。

三年之约（第 36 个周天开打，对手战力 125，筑基前老祖借你 2.5 倍战力）按 `tools/sim.js` 200 局模拟：只打坐胜算约 21%，懒散玩家（每届论道前出门两趟、不闭关、功法法宝只照掉落卡换、不强化）约 63%，跟着引导循环历练、闭关、升级、换克制的战技、强化兵器约 94%。

## 内容

- **奇遇事件 359 个**（基础 122 + 扩展包 237：秘境、宿敌与新秀、宿敌恩怨、坊市、宗门、人物委托与串门同行、灵宠洞府历法、奇遇链、主线补段、因果寻仇）：洞府、历练随时触发，大多有 2～3 个选项（救不救、抢不抢、信不信），带成功率或交手胜负。坊市里还有换货、讨价、开拍、送拍的坊市事件，四季与大势各有当季、当势才来的访客。扩展包里用到还没做的系统（长老人脉、恩怨、灵宠名册…）的事件先不出现，系统接上就自动上线，眼下上线 359 个（`node tools/check_events.js report`）。
- **功法 36 门**：心法管修炼，战技管战力并定攻击属性，秘术给特效；装着就涨熟练（入门→小成→大成→圆满→化境），圆满留一份“融会”；两门同属有共鸣，特定组合有 18 条有名的共鸣，凑齐时揭晓并记进图鉴（跨世保留）。来自寻宝、历练（血煞秘境掉魔道功法）、宗门宝库（各宗独有四门）、首领首杀、奇遇与主线；重复得到熟练 +20，仙神阶的两门要集齐三片残篇。
- **秘境**（筑基中期、三年之约之后；每年夏天开 6 个周天，一枚秘境令进一次，最多持 3 枚，每个夏季送一枚、坊市也卖）：主题按年轮换（剑气·金 / 百草·木 / 熔火·火 / 幽泉·水），场景换成秘境背景，下面两三扇门（天眼通多一扇，三成是“？”门），**一层点一下**：战（掉气血、得灵石灵矿、三成掉宝）/ 精英 / 宝（三成陷阱）/ 泉 / 奇（16 个秘境奇遇）/ 悟 / 商 / 最后一层守关。带入气血 100（法衣、青帝剑加），每过一层可以【带着 N 件收获离开】，打空了收获丢六成、负伤 4 周天；打穿开**秘藏**三选一（主题独有的天眼通、青帝剑、焚天诀、星斗残篇、锻魂阵图、魔角冠器方、灵宠蛋…，合计通关 3 次后出混元道经），首通给称号。局中时间不走，出来算 3 周天，中途关掉也能续。仙府现世时另能免令进一次 8 层的仙府（秘藏四选一）。
- **法宝三槽**：兵器管战力（开局），法衣管历练分数、少负伤、天劫承劫（筑基中期），饰品分修炼 / 财运 / 气运 / 寿元四种（元婴）；兵器 27 件、法衣 12 件、饰品 12 件、首领专属 11 件、镇宗法宝 3 件、器方 12 张。每件随机带 1～2 条词条（16 种，如锋锐斩妖 +5、克木对木属性战力 +10%、护主丁等不负伤），首领专属与打造品词条固定。**没有背包**：新掉落只弹一张对比卡（主属性、词条、强化继承后的结果、战力前后），【换上】或【熔炼】成灵矿，不选就熔炼；【锁定当前】以后更低阶的直接熔炼。**强化** +0～+9 花灵矿与灵石，每级超出部分 +6%，成功率 100% 递减到 40%，失败不掉级、下次 +10%；换装备时继承一半。天材地宝可**重铸**一条词条（二选一）。化神后**器炉**（器炉建成前借丹炉等级，5 级）用首领材料与灵矿按器方打造专属法宝，老祖旧剑链的终点是重铸玄霄。**灵矿**来自历练（斩妖 ×1.5，黑风岭 ×2、剑冢 ×3、星墟 ×4）、熔炼、坊市、宗门器堂、首领与奇遇。
- **灵宠 12 种 + 麒麟**（筑基起）：名册上限筑基 1、金丹 2、元婴 3、合体 4。【洞府】→ 兽栏，灵宠卡片横排，点卡 →【出战】（战力倍率 + 天赋）/【派岗】（五个岗位：护阵 修炼 +5%、觅食 兽粮、守田 灵田 +15%、看炉 成丹率 +6%、巡山 坏访客 −50%，类型对口 ×1.5）/【喂食】（兽粮，长按连喂），每个按钮写着“前 → 后”。等级 1～10，每级要兽粮 `6 × 1.5^级 × 阶`，倍率超出部分每级 +5%，出战的每趟历练另得一级的一成经验；5 级二选一分支进化（24 种形态，条件是药引、禁地趟数、好感、季节、首领材料，没试过的写“？”，试出来记进图鉴、跨世保留），10 级觉醒（天赋 ×1.5、品阶 +1、光环）。好感五颗心：出战、在岗、喂食、事件加，每心效果 +2%，闲着掉心，0 心会叼着碗出走。来源：坊市灵兽蛋（每届论道换一种属性）、拍卖、宗门御兽堂、采药偶遇（当地的种）、奇遇；名册满时【放生】得兽粮或【替换】。兽粮来自斩妖、觅食、坊市“兽粮一袋”、宗门。洞府场景里出战的趴在主角身边，干活的在灵田、丹炉、阵边、山道上。进化与事件里的药引付真的药引（灵田、坊市“药引一包”、秘境宝箱、觅食的灵宠）。
- **五行**：金克木、木克土、土克水、水克火、火克金。地图、宿敌、首领、九宗都有属性；战技克制此地历练分数 +8、克制对手战力 ×1.15，被克反之。地图属性去过才知道，对手属性交过手才知道。

## 安卓

`dist/xiantu.apk` 是离线单机安卓安装包（Android 5.0 及以上），游戏全部内置，不需要联网，存档保存在手机本地。

重新打包：

```
sudo apt install android-sdk-build-tools android-sdk-platform-23 apksigner zipalign default-jdk
bash tools/build_apk.sh
```

签名文件默认是 `android/release.keystore`（不进仓库）。以后更新版本要用同一个签名文件，才能覆盖安装、保留存档。
