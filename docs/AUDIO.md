# 音乐与音效

全部在 `src/ui/audio.js`，用 Web Audio **现场合成**，不带任何音频文件（整页只多了约 30 KB 代码）。
风格：修仙 + 像素——五声音阶为主，古琴 / 琵琶 / 笛 / 箫 / 磬 / 堂鼓的合成近似，加一点方波芯片味。

## 1. 结构

| 层 | 是什么 |
|---|---|
| 引擎 `auGraph(ctx)` | 音效总线、音乐总线各一个增益 → 压限 → 输出；音乐带一条回声；一段共用的白噪声；几张自定义波形表 |
| 乐器 `INS` | `qin` 古琴、`pipa` 琵琶、`di` 笛、`xiao` 箫、`lead` 方波主音、`sq` 方波分解、`bass` / `pbass` 低音、`pad` 铺底、`bell` 磬 |
| 打击 `DRUM` | `k` 底鼓、`s` 军鼓、`h` / `o` 镲点、`t` 堂鼓心、`T` 堂鼓边、`w` 梆子、`m` 木鱼、`c` 小镲、`g` 大锣、`r` 闷雷 |
| 乐谱 `TRACKS` | 简谱字符串，运行时解析、按 `AudioContext` 的时钟排程（所以 ×2 / ×4 不影响节拍） |
| 导演 `bgmScene()` | 每 150ms 看一眼游戏状态决定放哪首；**不用在各处埋点** |
| 音效 `SFX.xxx()` | 用同一套乐器合成；同名 40ms 内不重复 |

简谱写法：`1`～`7` 音级，`'` 高八度，`,` 低八度，`#` / `b` 升降，`-` 延音，`0` 休止，`|` 小节线（只给人看）；连写的几个音平分一个记号（`1'2'` = 两个半拍）。
声部：`{ i 乐器 | d: 1 打击, p 谱, u 一个记号占几个 16 分音符（旋律默认 2、打击默认 1）, o 移八度, v 音量, e 回声量, L: 1 战斗层 }`。
各声部按自己的长度循环——四小节的低音型垫在十六小节的旋律下面，不用抄四遍。

## 4. 接口

```js
SFX.tap(); SFX.skill('huo'); SFX.flip(2, 1); SFX.reveal(5);
BGM.play('vow');                                   // 手动指定，一直到 BGM.auto()
BGM.play('sorrow', { while: () => !$('#modal').hidden });   // 条件不成立时自动放开
BGM.auto(); BGM.stop();
BGM.cur;                                           // 现在放的是哪首（'' = 没放）
auSetVol('m' | 's', 0..5);                         // 音乐 / 音效音量
sfxPanel(open); sfxFloat(text); sfxMail();         // 弹窗、飘字、纸鹤的统一入口
tone(f, t0, dur, type, vol); noise(t0, dur, vol, cutoff);   // 旧接口，保留
```

加一首曲子：往 `TRACKS` 里加一项，再在 `bgmScene()`（或 `CN_BGM`：过场名 → 曲目）里指给它。
加一个音效：往 `SFX_DEF` 里加一个函数，用 `sxP`（乐器）/ `sxO`（一声）/ `sxN`（噪声）/ `sxD`（打击）/ `sxArp` / `sxPhrase`（一句简谱）拼。

## 5. 开关与混音

- 声音三态（【仙途】→ 设置 → 声音）：音乐与音效 / 仅音效 / 静音。“仅音效”时音乐停。
- 音乐、音效各一条 0～5 档的音量格（默认 3）。点第几格就是几档；点着的最高一格再点一下降一档。调音乐音量会把三态拨回有音乐。偏好存在本机（`soundMode` / `mv` / `sv`）。
- 第一次点按（或按键）之后才建 `AudioContext`。
- 页面隐藏、安卓切后台（`visibilitychange` / `pagehide`）时挂起，回来（`pageshow` / `focus` / 再点一下）恢复；安卓壳在 `onResume` 里补发一个 `pageshow`。
- 自动化测试（`navigator.webdriver`）里整个不出声、不建 `AudioContext`；地址带 `?audio=1` 可强开。
