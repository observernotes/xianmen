# 主线可走通性 · 验收矩阵与结论

验收方独立于修复线：不看修复线的测试过没过，自己列边界、自己写用例、自己跑。
验收对象是 **3.0（行动点制，docs/AP_PLAN.md）**；2.4.0-beta1 上跑出来的失败全部留作回归用例（第 3 节）。

- 用户反馈一（2.3.2）：“没有人让我进门派，然后就一直在第三章了。”
- 用户反馈二（2.4.0-beta1）：“第三年就打完了三年之约，对应剧情第五年才出来。”
- 用户反馈三（旧存档）：打赢了赶他下山的人，没入宗，停在第三章，看不懂下一步做什么。
- 硬规则：境界和主线不挂钩；剧情必须保证全部走通。

失败归成四个根因（都要进 3.0 的回归）：

**R1 入宗靠“等人来请”，而请的人被解锁卡的真实时间间隔挡着。**（用户反馈一的根因）
三宗争徒的弹窗要三样同时成立：筑基、【宗门】解锁卡已开、这个月人在洞府。【宗门】是解锁表里的系统卡，两张系统卡之间要隔 6 分钟**真实时间**（`L.onbHold`），而且每一张“强制解锁”的卡（战技、访客、天劫、灵宠……）都会把这只表重新归零。
量出来：×1 时【宗门】卡在第 130～155 月（sim 口径是第 52～64 月，因为 sim 不算真实时间）；**×4 时在第 848 月**（`F-x4-popup`），一辈子等不到。2.3.2 没有“三张帖子”这场戏，弹窗是唯一的入口——所以 ×4 的玩家就是“没有人让我进门派”。2.4 加了“三张帖子”，但它又被 R3 压着（界面实测 ×4 时第 116～197 月才出）。

**R2 第八章“天骄榜前二”是个定时炸弹。** 榜上对手的战力按日历指数增长（`rivalCurve = exp(A + 0.0185 × tick)`），玩家到渡劫圆满后战力封顶。进度稍慢的局（散修路线、先拒后入、部分抉择）到第八章时已经追不上：压着不飞升 800 多月，最高名次停在第 3～4，然后坐化。10 条失败是它。不压着就是“飞升了，第八、九章没做完”。**打不过点名的人没有任何兜底**——随手玩的三局全部在第五章（楚天阔）停到飞升。

**R3 ×4 时解锁卡跟不上，整个成长被拖垮。** `F-x4-guided` 在“三张帖子”里入了宗，照引导玩，仍然停在第五章、第 1276 月坐化：每张系统卡 6 分钟，×4 下是 60～180 个月一张。

**R4 2.3.1 旧档跳章。** 2.3.1 的章按境界推，旧档里可能已经记着“第七章主线完成”（当时是击败血无涯）。读进来以后章退回第二章，但第七章的新主线（真相 + 正魔大战）被旧成绩顶掉，走到那里直接跳过，抉择六不出。

警告（不算失败，但都是“境界与主线挂钩”的实证，共 27 种）：
- 晋升内门 / 真传 / 圣子要筑基 / 金丹 / 元婴（`L.SRANKS[r].r`）；赵乾、楚天阔、血无涯要你修到金丹初期 / 化神初期 / 合体中期才肯上台（`L.rivalRefuses`）；散修要的首领数受地图境界门槛限制。127 局里第五章平均有近百个月卡在境界上，第七章同样。**目标卡在这些时候一个字不提境界**（“对楚天阔 3% → 80%”，实际是他根本不上台）。
- 被除名（抉择六选魔道）以后，三宗争徒的弹窗 / “三张帖子”那场戏（“筑基消息传出，三宗来抢人”）会在第七、八章补放，还能再入一次宗，身份从外门弟子重来（30 局）。
- 四个有条件的选项（问一句 / 止战 / 昭告天下 / 拔出玄霄）在随机局里点不到：覆盖不足，要造专门的局。

### 3.3 剧情滞后的诊断（用户反馈二）

**现象（界面实测）。** 三年之约第 36 月了结，对应的戏：×1 照引导玩、一回洞府就再出门的玩家——**一直没播**（跑到第 90～330 月都没有）；×4：第 101～173 月才播（隔 65～137 月）。第二章开章（story_r1）隔 69～154 月，“进前 60”的戏隔 77～215 月，赵乾落败隔 69～214 月。用户看到的“第三年打完、第五年才出”已经是运气好的。

**原因：五道闸串联，每一道单看都合理，叠起来就是没有上限的延迟。**

| # | 闸 | 在哪 | 单独的效果 |
|---|---|---|---|
| ① | 节拍只在“这个月人在洞府、剧情队列是空的”时才判 | `storyline.js` `L.storyTick`：`if (L.busy(st)) return; … if (st.storyQ.length) return` | 队列里只要压着一场任何戏，后面的节拍全停（队头阻塞） |
| ② | 节拍严格按表顺序、带最小间隔（open 2 / mid 6 / pre 3 月） | 同上 `GAP`、`break` | 约战赢了以后最好情况也是：高潮戏 +4 月、章末 +8、第二章开章 +8、三张帖子 +16（sim 里量的：`c1_climax:40, c1_end:44, c2_open:44, c2_mid1:52`） |
| ③ | 界面只在“人在洞府 + 没有弹窗 + 离上一次主动打断 ≥ 3 个月”时才从队列里取一场 | `clock.js` 包的 `processQueue`、`L.notifyGate` | 老祖气泡、解锁卡都算“主动打断”；回洞府那一下经常刚好被气泡占掉 |
| ④ | **有解锁卡在排队时，剧情一律不出** | `talk.js`：“解锁卡排在剧情前面” | 解锁卡自己也受 ③ 管，还要老祖气泡不在场。实测：人在洞府、能打断、队列里有戏的 16 个时刻里，16 次都因为“解锁卡排队”没出戏 |
| ⑤ | 解锁卡之间隔 6 分钟真实时间，且一次只开一张 | `clock.js` `L.onbHold`、`onboard.js` | ×4 下是 60～180 个月一张；④ 让剧情跟着它一起等 |

另外两处放大：剧情队列是先进先出的一条（主线戏和灵宠、访客那类闲戏排在一起）；在外期间一律不出（照引导玩的人大部分月份都在外）。

**设计结论。**

1. **关键剧情不该是“可节流的打断”，应该是事件结算的一部分。** 约战、论道、突破、晋升这些本来就是阻塞弹窗，它们引出的戏（climax / end / 下一章 open / 带抉择的节拍）要当场接在后面出，不经过 ①③④。这就是 AP_PLAN §4.2 的结算链，方向是对的。
2. **④ 必须删。** 解锁卡不能挡剧情；反过来，关键剧情出完以后本季再出解锁卡。
3. **⑤ 的真实时间间隔必须删**（它也是 R1、R3 的根因）。节流只能用游戏内的单位（3.0：每季至多一张排队类解锁卡）。
4. **② 的顺序与间隔只留给闲戏（mid）**；climax / end / open 不受同章 mid 没放完的牵连——mid 没到点就过期，不能反过来把高潮戏拦住。
5. **① 的队头阻塞要拆**：主线戏和闲戏分两条队列，闲戏永远不挡主线。
6. 3.0 里没有“在外”，③ 的“在外不出”自然消失；“一季一次主动打断”只对闲戏、访客保留。

验收口径（3.0）：H1 `shown − due === 0`，由 `tools/story_accept3.js` 用两套口径查（逻辑层记的 `st.story.lag`，和验收方自己在每个行动 / 每张链卡之后观察“条件第一次成立的 seq”与“那场戏出链的 seq”）；界面层另查“关键戏开播时上一张关掉的层是它的结算卡”。

### 3.4 目标卡有没有说清差什么（用户反馈三）

用户那份旧档的形状（`tools/story_fixtures/syn_ch3_nosect_beatzhao.json`：打赢了赵乾、没入宗、第三章）在 2.4.0-beta1 上：

    目标卡：第三章 升真传·败赵乾 ｜ 进度：先拜入宗门 ｜ 下一步：换一次阵法 【去】→ 阵法页

- “先拜入宗门”没说怎么拜：宗门页只写“约 N 月后宗门再来招揽”，玩家什么都做不了，只能等（而且 ×4 下等不到，R1）。
- 【去】跟的是“变强建议”的第一张牌，和主线差的那一项没有关系。全程实测【去】都有反应，但它从不指向主线缺的那一步。
- 卡在境界时（晋升要金丹、楚天阔要化神才上台）目标卡只显示“贡献 3639 → 4000”“对楚天阔 3% → 80%”。

3.0 的断言（K 类）：`L.mainActs(st)` 非空；每一项要么 `ok`，要么 `why` 是一句具体的话；`goalNow().next` 取主线差的那一项；ok 的行动做下去状态必须变。这份旧档迁移后必须出现【下战帖】或【讨伐首领】与【拜山门】。
