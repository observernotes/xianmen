# 最终调数值时要处理的事项

各系统开发时记下、留到最后统一校准的问题。

- 宿敌从拍卖拿到东西的永久加成没有单人上限：lazy 玩家从不参加拍卖，最强的宿敌会涨到 ×1.73。SYSTEMS §13 写的是每人上限 ×1.3（含拍卖与奇遇）。
- sim 里仍未达标的行（历法与坊市完成后共 10 行，都不是门槛行）：各境界时长、约战前已筑基、击败宿敌的时间、天骄榜第一的时间、宗门身份晋升时间、突破失败次数、lazy 的三行。天劫与道心因果之后 11 行：多了 guided 飞升周天（558，见下面“道基超预算”）。
- 页面体积：所有美术合并后单文件约 1.48 MB，DESIGN 阶段五的目标是 ≤ 1 MB——发版前看能否压缩（字体子集、art.js 缓存逻辑）。
- longrun 现在约 30 分钟（机器人通过界面逛坊市）。
- 突破失败次数（天劫与道心因果之后）：BT 基础值已整体 −0.10（金丹起），但 guided 把护劫手段全用上、临阵吞丹补到封顶，几乎每次都是 100%——一世失败中位数仍是 0（目标 2～6）；lazy 1（0～3）。要落到 2～6，得在最后统一调：再压 BT、给护劫手段降一档，或让 guided 不再“补满”（SYSTEMS §9 写的是“有就全用”）。
- 道基超预算：guided 成功率常是 100%，评价分布 完美 50% / 上 27% / 中 16% / 下 8%，渡劫期道基 +15%、一世 +18%（§18 预算 +12%）。guided 飞升 606（`nodaoji`）→ 558，掉出 580～660；天骄榜第一 324 → 288。可选：评价门槛跟着成功率走（比如余量按 p 未截断前算）、每档少给一点，或最后把 L.TR 后段拉长。
- 合并灵宠之后 guided 飞升 530（`nodaoji` 574）：灵宠与道基叠在一起比 580～660 快了一截，最后统一校时一起算。
- 因果目前一世中位数 0 条：能记因果的事件多半还闸在秘境、恩怨、人脉后面（EVENT_INTEGRATION 第四刀列了），那几个系统上线后再看寻仇事件（ev_karma.js）的频率与赔礼价钱。
- 合并秘境之后 guided 飞升 514（`norealm` 543）、天骄榜第一 264（`norealm` 312）：秘境单独对照时基本持平（603 → 607），与灵宠名册、天劫道基叠起来快了约 5%。可调的口子在 `src/logic/realm.js` 的 `L.MJ`：`rew`（一间战斗房的灵石，现 0.12 × 家门口腹地历练奖励）、`dropP`（战斗房三成掉宝）、层战力 `recD` / `powStep`（掉血）、秘境令（每夏一枚 + 坊市 `token` 基价 500）。guided 一世约 47 局、几乎不出局；“历练收入 : 被动收入”因为每局出来那 3 个周天降到 0.85（算上秘境的灵石约 1.3）。秘境事件里能记因果的 `realm_altar`、`realm_sword_slave` 已上线。
- 宗门身份（宗门加深之后）：人脉让圣子从 112 推到约 173（只差人脉卡住约 50 周天），但长老 / 太上 / 宗主（183 / 286 / 358）仍是被境界卡着的——化神 / 合体 / 大乘一到就升，那时三位长老的支持早已 80～100。境界节奏拉长到 §3.12 以后再看；要是那时宗主还早，可以让支持随时间回落一点（人走茶凉），或把宗主的门槛改成两位 ≥ 80。可调的数在 sect2.js 的 L.FAV（任务 +3、送礼 +6 只送到 40、入宗 10）。
- 宗门当值（每周天一趟乙等历练贡献的 0.3）与出师（8 趟）让中后期贡献偏多，宝库六格限量兜着；“历练收入 : 被动收入”与灵田炼丹合并后 1.06 → 1.07；guided 传授、讲法各占 2 个周天，飞升 509 → 524。
- 三人会武：对方两名弟子按你的小层 − 16 算（L.TRIO_LV），guided 留下的两个徒弟约赢 4 / 7 场；徒弟成长 0.02 × 灵根 / 周天在 §11 原文里，金丹出师大约要 160～250 周天。
- 洞府地块、建筑与阵法（第九刀，200 种子）：guided 飞升 537（`nohome2` 回到地块之前 525），三年之约门槛 94% / 17% 不变。和 SYSTEMS §6.1 不一样的两个数：
  静室闭关倍率按“替换原洞府本体的 +0.05/级”取 **+0.05/级**（SYSTEMS 写 +0.08，满级会比原来多 +0.36，guided 约快 5%）；聚宝阁被动灵石取 **+2%/级**（SYSTEMS 写 +6%，满级 +72% 时“历练收入 : 被动收入”1.08 → 0.54，+2.5% 时 0.78，+2% 时 0.87）。
  guided 一世末的洞府：8 块地，聚灵阵 28、灵田 28、丹炉 20、静室 12、聚宝阁 12、藏经阁 10、器炉 15、兽栏 12（灵泉、迎客亭、传送阵挤不进来——迎客亭 2 万起、传送阵 30 万 × 4^级，9 级要 26 亿，一世到不了）；
  前期（筑基 → 元婴）慢一点（洞府本体不再加闭关，静室筑基后期才开、要从 1 级升），后期（大乘、渡劫）快一点（藏经阁熟练 +100%、聚宝阁），合起来飞升慢约 2%；天骄榜第一 300 → 312（器炉要先占一块地才能打造）。
  阵法：guided 一世约 7 张阵图、换阵 16 次，渡劫阵护劫 7 次——guided 本来就能把成功率补到 100%，渡劫阵主要省下临阵吞丹，几乎不影响道基。
  可调的口子：`L.HV`（home.js 每级效果）、`L.ZV`（formation.js 阵法强度）、各建筑 base / grow（CONTENT §7）；手持灵石 / 收入 21.1 → 17.1（建筑是灵石去处），这一行反倒达标了。
