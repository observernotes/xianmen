## 1. 设计原则：深度不加复杂度

开罗的游戏并不简单，但从来不让人觉得复杂。拆开看是这七条，本方案每一处都按它审过：

1. **规则少，组合多。** 每个系统要玩家“记住”的规则不超过 3 条（见下表）。深度来自东西之间的搭配（五行 × 招式 × 词条 × 敌人特性），不来自规则条数。
2. **一个按钮，背后多层。** 战斗只有一个大按钮（绝招）。它同时是：伤害、破招、破罩、救命。新手只知道“亮了就按”；熟手会留到对面蓄力时再按。同一个按钮，两种水平。
3. **复杂度按时间一层一层揭开。** 第一场战斗只有“普攻 + 绝招”；第 2 趟才出现第二个招式格；第 3 趟才出现带罩的精英；连携、印记、洗练、套装都在第二章以后。任何一刻，屏幕上新出现的东西只有一样（沿用 KAIRO_PLAN “一次只教一件事”）。
4. **数字直观。** 界面上只出现三种数：**×倍数**（招式）、**▲差值**（换装）、**N/M 进度**（保底、心愿、熟练）。不出现百分比叠乘、不出现“超出部分 ×6%”这种话。内部公式可以复杂，露出来的永远是结果。
5. **对错当场看得见。** 克制：黄色大字“克”+ 罩碎的声音；被克：灰色小字“打不动”。破招：慢镜头 + “破招”二字。没有一个决定的后果要等到结算才知道。
6. **默认就能赢，用心赢得多。** 全自动（不按任何按钮，怒气满了自动放）也能过“推荐战力 ≥ 你”的关；会破招、会换克制的人能越 0.3 倍战力打、评价高一档、牌多一张。sim 也因此跑得通。
7. **不做的事**（都想过，都删了）：格子走位、多角色编队、手动选每一招、蓝条 + 怒气两条资源（只留怒气）、装备栏位超过三格、词条数值随机档（I / II / III）、背包整理、掉落鉴定。

**规则预算**（玩家需要理解的全部规则；实施时如果发现要多讲一条，先回来改设计）

| 系统 | 玩家要懂的规则（就这些） | 第一屏能看懂吗 |
|---|---|---|
| 战斗 | ① 招式自己会放 ② 怒气满了按大按钮 ③ 对面蓄力时按 = 破招 | 血条、怒气条、一个大按钮（`02_battle.png`） |
| 五行 | ① 箭头指向谁就克谁 ② 克制 = 更疼，而且只有克制能破罩 | 出发页一行“克木 ✓ 打不动土 ✗”+【换】（`01_prep.png`） |
| 技能 | ① 每样东西带一招（战技、兵器、秘术各一招，心法是被动） ② 用得多会升级 | 功法页三行，每行一个图标一句话（`06_skills.png`） |
| 刷宝 | ① 颜色 = 阶 ② 星 = 词条多一条 ③ 钉了心愿，8 趟必出 | 翻牌（`04_loot.png`） |
| 炼器 | ① 强化：数字变大 ② 淬灵：改五行 ③ 洗练：换词条 | 法宝详情三页，一页一个按钮（`05_forge.png`） |

## 2. 【P0】历练里的战斗

### 2.1 一趟历练长什么样

一趟 4 个月 = **4 个节点**，一月一个，时间条每过一个节点走一格（KAIRO_PLAN 的“在外”态不变：路上不弹任何外面的事）：

| 行事 | 节点 1 | 节点 2 | 节点 3 | 节点 4 |
|---|---|---|---|---|
| 斩妖 | 战（小怪 ×1） | 战（小怪 ×2） | **精英**（带罩） | 归途 · 翻牌 |
| 寻宝 | 战 | 宝（多一张牌） | **精英**（守宝的） | 归途 · 翻牌 |
| 采药 | 采（灵草、药引） | 采 | 战（小怪 ×2） | 归途 · 翻牌 |

- 5 个月的图（万妖山脉起）多一个“战”；6 个月的图（东海龙宫起）再多一个“精英”。禁地的精英之后，首领现身时节点 4 变成二选一：【挑战首领】/【带着东西回去】。
- **气血一路带着走**：三场共用一条血，场与场之间回 12%。所以“第二场要不要吞丹”“精英前要不要撤”是真的决定。
- 现有的途中遭遇（一趟最多一次的二选一事件）插在节点 2 之前，不变。
- 画面（`02_battle.png`）：上半是历练场景（现有 `ART.drawAdventure`），主角在左、敌人在右；下面依次是**行程条**（战—战—精—宝，当前节点发亮，右边累计“已得”）、**我的气血 / 怒气**、**招式栏**（三格，自动，转冷却）、**大按钮（绝招）+ 丹 + 撤**、一行战报。目标卡缩成一行留在底部。

### 2.2 一场战斗的规则（半自动回合制）

- 双方轮流出手，一轮 = 我一下、它一下（多只小怪时每只各一下）。**×1 时一轮 1.0 秒**（人生第一场 1.4 秒），×2 时 0.5 秒。小怪 4～6 轮、精英 8～14 轮、首领 14～20 轮。一趟三场合计约 25～40 秒。
- **我方每轮自动选一招**，优先级固定：战技（冷却好了）＞ 器技（冷却好了）＞ 秘术（条件满足）＞ 普攻。玩家不用选。
- **怒气**：我出手 +20，挨打 +10，满 100 后**大按钮亮起**，按下 = 这一轮改放绝招（伤害 ×3，无视罩的减伤）。设置里可开“怒气满了自动放”（默认：第一章关，教你按；第二章起由玩家定）。
- **敌人**：小怪只会普攻。精英和首领每 4 轮**蓄力一轮**（头顶红字“蓄力！”，这一轮它不打你），下一轮打出 ×2.2 的重击。**蓄力那一轮放绝招 = 破招**：重击取消，飘“破招”，这一趟评价 +1 档的条件之一。
- **护罩**（只有精英、首领有，3～5 格）：罩在的时候它受到的伤害 ×0.6。**只有克制它的招式能削罩**（每招 1 格，绝招不管属性削 1 格、克制的绝招削 2 格）。罩碎 = 它晕一轮 + 之后两轮受伤 ×1.3。——这就是“克制为什么要紧”。
- **丹**：每场可以吞一枚疗伤丹（回 25% 气血），带了才有；按钮常驻。**撤**：随时可撤，带走已经到手的，评价最多丙，不负伤。
- **输了**：气血归零 = 这一趟到此为止，带回已得的一半，负伤 3 月（原“丁等”的后果）。第一场就倒 = 丁；至少过了一场 = 丙。
- **关键时刻的停顿**：怒气满且对面在蓄力时，第一章里时间**停住等你**（`03_battle_ult.png`，一行字“放绝招，或者硬吃这一下”）；第二章起改成 2.5 秒慢镜头，不按就过去。这是整场战斗唯一会停下来等人的地方。
- **速战**：这一格（地点 × 深度）已经拿过甲、且战力 ≥ 推荐 × 1.8 时，出发页主按钮旁出现【速战】：三场用同一套引擎瞬间算完，只播每场 1 秒的结果条，然后直接翻牌。刷宝不磨人。
- **第一次看得懂**：人生第一场只有普攻和一个会亮的大按钮；第一次遇到蓄力、第一次遇到罩、第一次克制，各自在出现的那一下停 1 次、屏幕中央一行 ≤ 12 字（“它在蓄力——放绝招打断它”），之后永不再停。不出老祖对话框。

### 2.3 评价怎么来（接上现有的丁丙乙甲天）

评价不再掷骰，按打出来的结果定；奖励倍率 `L.RATE_M`、深度解锁（乙）、札记任务都不用改：

| 评价 | 条件 |
|---|---|
| 丁 | 第一场就倒 |
| 丙 | 没打完三场（倒在半路，或主动撤） |
| 乙 | 三场全胜 |
| 甲 | 全胜，且归来气血 ≥ 45% |
| 天 | 全胜，且归来气血 ≥ 75% |

吞丹不降评价；破招 ≥ 1 次且全胜时，气血门槛各降 10 个点（45% → 35%，75% → 65%）。

### 2.4 战前能做的决定（出发页，`01_prep.png`）

出发页从上到下：地点 · 深度 + 推荐战力 / 你；行事三页；**这一趟会遇到**（三个敌人格：小人、五行徽、精英红框；没见过的画剪影和“？”）；**克制条**（一行：你带的战技图标 +“克木 ✓ 打不动土 ✗”+【换 ▸】）；带着（三个招式图标、气血、疗伤丹 ×N）；**这里掉什么**（§5.3）；主按钮【出发 · 4 月】。

- 【换 ▸】= 弹出“你有的战技 / 兵器”小列表（≤ 4 行，每行写“克谁”），点一下就换好回到出发页。**换克制是两次点击。**
- 克制条只在“身上的招克不了这趟的精英”时是红的；全克得动是绿的一行“都克得动 ✓”，没有按钮。
- 阵法、灵宠助战沿用现有系统的开放时间，开了以后在“带着”那一行多一个图标，不另做界面。

### 2.5 和时钟、存档的配合

- 出发 → 进入“在外”态；**月份由节点推进**，不再按秒走：打完一个节点 `L.flow(st, 1)` 过一个月，时间条走一格。打得慢不会多耗月，挂机也不会偷走时间。
- 战斗中切到别的面板 = 战斗暂停；关面板继续。在外期间外面的消息照旧进纸鹤。
- 大节点前强制归来（KAIRO §3.3）照旧：出发时月数不够就不让走。
- **随机数**：出发时生成 `st.exp.seed`；每个节点的引擎用 `seed + 节点序号` 播种。存档只存“到了第几个节点、当前气血、怒气”，读档从这个节点的开头重打——同一个种子，暴击序列一样，读档刷不出别的结果；玩家的按键不同，结果才不同。
- 连续历练（金丹）照旧：一趟打完气血不回满就接下一趟。

## 3. 【P0 / P1】技能：每样东西带一招

### 3.1 结构（不加槽位，全用现有的）

| 来源 | 给战斗什么 | 怎么触发 | 第一章就有吗 |
|---|---|---|---|
| **心法**（槽 1） | 一个被动（回气、回血、减伤……）；它的五行是你的**护体属性**（决定谁打你更疼） | 常驻 | 开局自带《引气诀》 |
| **战技**（槽 2） | 一招主动（伤害最高的那招），决定你的**出手属性** | 自动，冷却 3～5 轮 | 第 2 趟保底掉《裂金斩》 |

招式栏永远只有三格（战技 / 器技 / 秘术）+ 一个大按钮。**没有“学技能”“技能点”“技能树”**：拿到东西就有招，装上就用。

## 4. 【P0 / P1】五行在战斗里

### 4.1 规则（玩家只需要懂两条）

1. **箭头指向谁就克谁**：金→木→土→水→火→金（`ART.elemWheel`，功法页和出发页的【换】里常驻）。
2. **克制 = 伤害 ×1.3，而且只有克制的招能削罩**；被克 = 伤害 ×0.8。（五行只看招式：战技、器技、有属性的绝招。普攻没有属性。）

| 情况 | 效果 | 画面 |
|---|---|---|
| 我的招克它 | 这一招 ×1.3；削罩 1 格 | 黄色大字 + 红底“克”；罩格碎一格的清脆一声 |
| 我的招被它克 | 这一招 ×0.8；削不了罩 | 灰色小字；战报“打不动” |
| 它克我的护体属性（心法的五行） | 它打我 ×1.15 | 我的血条闪红边 |
| 我的护体克它 | 它打我 ×0.9 | — |
| 罩碎 | 它晕 1 轮；之后 2 轮受伤 ×1.3 | `ART.skillFx('brk')` + 停 0.2 秒 |

原型结果（§8.3）：带克制的招，相当于战力 ×1.7～2；带被克的招，相当于战力 ÷1.4。**同一趟里“换一门克制的战技”比“多强化两级”管用**——这就是换装的理由。

### 4.2 让玩家真的会去换

- 每张图的三个深度**主属性不同**（§7.2）：后山野林 外围木 / 腹地精英土 / 禁地火，首领木，三年之约的对手水。第一章一路打下来，五种属性各需要一次。

- 现有的“克 X”词条改成“打 X 系 +20%”（原来是对决战力 +10%）；「藏锋」改成“被克时不减伤害”。地图五行、对手五行“第一次见过才显示”的规则不变。

### 4.3 第二层（第二章以后揭开，P1）

- **相生连携**：上一招的五行“生”这一招（木→火→土→金→水→木），这一招 ×1.3、怒气 +10，飘“连携”。第一章里只有战技 + 器技两招，凑巧连上会生效但不讲；第二章入宗后老祖一句话点破，功法页的两招之间画一条连线。

### 5.5 揭晓的仪式（`04_loot.png`）

1. 归途节点走完，结算卡升起：先盖评价章（现有 `ART.stamp`），一行“三场全胜 · 剩气血 52% · 破招 1 次”。
2. 牌一张张扣着排出来（`ART.lootCard('back')`），**按价值从低到高排**，最好的在最右。带星的牌背会轻轻抖、四角闪光（牌背第二帧）——“这张有货”，但不告诉你是几星。
3. 点一张翻一张（0.25 秒翻面）；长按 = 全翻。每翻一张一个音：无星 `do`、★ `mi`、★★ `sol`、★★★ 高八度 `do` + 锣；音高按翻的顺序上行，所以一路翻过去是一句上行的旋律。
4. ★★ 以上：牌下升起品阶光柱（现有 `ART.dropBeam`）；★★★：先慢 0.6 秒、全屏金闪、震一下，星一颗一颗钉上去（每颗一声）。
5. 翻出比身上强的法宝：牌下方直接出对比行 `▲ +N【换上】【收】`；不如身上的默认【熔】是主按钮。心愿达成有单独一条红框。
6. 最后才是“你变强了 / 离目标”两段（KAIRO §6.1，不变）和【回洞府】【再去一趟 ▸】。

### 5.7 为什么想再去一趟（循环）

**打 → 翻牌 → 换上 / 熔 → 强化 / 淬灵 → 打更深的**，每一步都留一个“差一点”：

- 出发页上那格黑剪影、“心愿 3 / 8”、“距天命 7 件”。

- **趁势深入**（P1，把金丹的“连续历练”提前成第一章的一个选择）：三场全胜且气血 ≥ 50% 时，归途节点多一个按钮【再深一层 +2 月】：不回家、气血不回、直接打下一个深度的精英，赢了多翻 2 张且星率 ×1.5，输了这一趟的牌丢一半。贪不贪，自己定。

## 6. 【P0 / P1】炼器

选定的一套：**强化（含开锋）→ 淬灵 → 洗练**，三样，一样比一样晚开；后期再加**打造**和**同源**（套装）。全部在“法宝详情”这一张卡上做（点装备页任意一件法宝打开，`05_forge.png`），不新增入口。

| 页 | 一句话 | 什么时候开 | 花什么 | 主按钮 |
|---|---|---|---|---|
| **强化** | 数字变大 | 第一章：熔过第一件法宝之后 | 灵矿（+ 灵石） | 【强化 · 矿 26】 |
| **淬灵** | 改兵器的五行 | 第一章：攒到 3 枚同系灵核时（子项，不出卡） | 灵核 ×3 + 灵矿 | 【淬成 土】 |
| **洗练** | 换一条词条 | 筑基（第二章） | 器纹石 ×1 | 【洗这条】 |
| 打造 | 照器方打一件 | 化神（不变；第一张器方提前到金丹） | 首领材料 + 灵矿 | 【打造】 |

### 6.1 强化与开锋

- 强化规则沿用现有（+0～+9、成功率、失败保底、换装继承一半）。**开放时间从“炼气圆满”提前到第一章中段**。
- 界面只写结果：`+2 → +3　战力 19 → 20　成功 90%`，一条灵矿进度条。
- **开锋**（新，P1）：强化到 +3 / +6 / +9 时停一下，三选一（三个图标 + 各一句 ≤ 8 字）：
  - 锋：这件的伤害 +6%　· 灵：器技冷却 −1（只能选一次）　· 韧：气血 +8%
  - 选了不能改（换一件新的重新选）。九级强化里只有三次决定，每次都是清楚的三选一。

### 6.2 淬灵（第一章的炼器深度，P0）

- **灵核**：每个精英掉它那一系的灵核（`ART.core(el)`）。3 枚同系灵核 + 灵矿 `10 × 阶` → 把一件**兵器**淬成那一系：器技的五行、特效颜色跟着变。可以反复淬。
- 用处一句话：**手里只有一把好剑，也能让它克下一关。** 第一章的典型用法：★★ 的精钢剑属金，克不了腹地的铁背熊（土）；外围精英老藤王掉木灵核，攒 3 枚把剑淬成木，再去打熊。灵核把“上一关”和“下一关”串成一条链。
- 法衣淬灵（改护体属性，覆盖心法的五行）在法衣开放后（筑基）一并开，规则相同。

### 6.3 洗练（第二章起，P1）

- 现有的“重铸”（1 个天材地宝重抽一条，二选一保留）改名洗练，货币改成**器纹石**（`ART.icon('rune')`）：熔炼带星的法宝得“星数”颗，打首领得 1 颗。天材地宝不再用于洗练（留给突破和坊市）。
- 做法：点一条词条 →【洗这条】→ 出“旧 / 新”二选一。其余词条不动（等于天然锁定，不需要“锁”这个概念）。
- 保底：同一件第 6 次洗练，必出这件没出过的词条里“战斗类”的一条。金词条洗不掉也洗不出。

### 6.4 熔炼、材料与闭环

| 材料 | 从哪来 | 用在哪 |
|---|---|---|
| 灵矿 | 历练每趟、“一堆灵矿”牌、熔炼（`4 × 2^阶`，不变） | 强化、淬灵、打造 |
| 灵核（五系） | 精英牌（60%）、评价牌（18%） | 淬灵 |
| 器纹石 | 熔炼带星的法宝、首领 | 洗练 |
| 首领材料 | 首领（首杀 2、重刷 1） | 打造（不变） |

闭环：**刷出来的每一件都有去处**——比身上强：换上（旧的那件强化继承一半）；不如身上：熔成灵矿，带星的另给器纹石；精英掉的灵核改五行去克下一关；首领材料打专属。没有“垃圾装备”，也就不需要背包。

### 6.5 后期（P2）

- **同源**：兵器、法衣、饰品里有 2 件 / 3 件出自同一个首领（专属或用它的材料打造的）→ 2 件：这位首领的独有器技冷却 −1；3 件：绝招多一个它的特效（狼王：斩杀线 35% → 45%）。只按首领分 11 组，界面是法宝页标题下一行小字“同源 · 狼王 2/3”。
- 打造的第一张器方（狼牙项链）提前到金丹，随饰品槽一起开。

## 8. 【P0】数值

### 8.1 从战力到战斗属性

战力 `T = L.power(st)` 的含义、来源、界面上的数都不变。战斗里只是把它拆成两半：

```
攻 = √T　　　气血 = 10 × √T × (1 + 法衣 / 坚韧等加成)
敌人：战力 Q = 推荐战力 rec(k, d) × 节点系数；攻 = √Q × 攻系数；气血 = 10 × √Q × 血系数
```

| 敌人 | 节点系数 | 血系数 | 攻系数 | 罩 |
|---|---|---|---|---|
| 小怪（两只时各 ×0.6 血） | 0.6 | 0.5 | 0.9 | — |
| 精英 | 1.0 | 1.0 | 0.85 | 3（硬壳 4） |
| 首领 | 1.6 | 2.0 | 1.1 | 5 |
| 对决的对手（§8.4） | 1.0 | 1.5 | 1.5 | 0～3 |

界面上显示的气血是整数（开局 T = 10 → 气血 32；章末 T ≈ 100 → 100 上下；数字小、好读）。战力里现有的战技倍率 `L.ZHAN_M` 保留（它让 T 变大，也就让攻和血都变大）；招式的伤害倍数是另一层。

### 8.2 伤害公式（引擎里的全部数）

```
一下的伤害 = 攻 × 招式倍数 × 五行(1.3 / 1 / 0.8) × 浮动(0.8～1.2) × 暴击(15% 概率 ×1.8) × 状态(破甲 / 易伤…) × 罩(在则 ×0.6)
敌人打我 = 敌攻 × (普攻 1 / 重击 2.2) × 护体五行(1.15 / 1 / 0.9) × 浮动(0.8～1.2) × 暴击(10% 概率 ×1.5)
气势：每场开打时双方的攻各乘一次 (0.7～1.3) 的随机数（画面上是开场一句“气势如虹 / 气势平平 / 被压了一头”）
怒气：出手 +20，挨打 +10，满 100；绝招 ×3
场间回血 12%；疗伤丹 +25%；蓄力周期 4 轮；罩碎晕 1 轮、易伤 ×1.3 两轮
```

所有常数放在 `L.BT = { hpK: 10, vari: 0.4, crit: 0.15, critM: 1.8, mom: 0.3, ult: 3, rage: [20, 10], heavy: 2.2, heavyEvery: 4, shieldCut: 0.6, brk: 1.3, brkLen: 2, between: 0.12, pill: 0.25, mob: {…}, elite: {…}, boss: {…}, duel: {…} }`，一处调。

### 8.3 原型跑出来的曲线（`tools/battle_proto.js`，一趟 = 小怪、小怪、精英；每格 4000 次）

全自动（怒气满就放、不吞丹）：

| 战力 / 推荐 | 无克制：三场全胜 | 甲以上 | 带克制：全胜 | 甲以上 | 被克：全胜 |
|---|---|---|---|---|---|
| 0.55 | 7% | 0% | 95% | 52% | 0% |
| 0.7 | 34% | 3% | 100% | 86% | 4% |
| 0.85 | 62% | 15% | 100% | 97% | 16% |
| 1.0 | **82%** | 35% | 100% | 100% | 40% |
| 1.2 | 94% | 63% | 100% | 100% | 65% |
| 1.5 | 99% | 88% | 100% | 100% | 87% |
| 1.8 | 100% | 97% | 100% | 100% | 97% |
| 2.4 | 100% | 100% | 100% | 100% | 100% |

会玩（留绝招破招 + 带一枚疗伤丹），无克制：0.55 → 45%，0.7 → **85%**，0.85 → 98%，1.0 → 100%。

读法：

- 旧公式里“战力 = 推荐 → 乙（八成）”这个锚点保住了（82%）。原来“推荐 × 1.65 → 甲”也大致对得上（1.5 → 88%）。所以**地点推荐战力表 `L.REC`、奖励表 `L.REW`、深度解锁都不用改**。
- 克制 ≈ 战力 ×1.7～2（0.55 带克制 ≈ 1.2 无克制）；被克 ≈ ÷1.4（1.0 被克 ≈ 0.72 无克制）。会玩 ≈ ×1.4。两样叠起来能越一个深度打——这是给高手的空间，不是必须。
- 一趟三场合计 13～16 轮（×1 约 15～20 秒纯战斗），加走路与翻牌符合 §2.6 的 55～85 秒。

## 接口（线 C1「战斗」与 C2「刷宝 + 炼器」、C3「过场」之间；C1 维护）

> 原则：C1 只往 `src/logic/battle.js`（新）、`src/logic/expedition.js`、`src/ui/battle.js`（新）里写战斗；不动 `gear.js` 的词条表与掉落。C2 提供下面标“C2”的函数；C1 用 `if (L.xxx)` 判断，没有就走兜底（合并后删兜底）。

### 1. 历练一趟（`st.exp`，C1）

```
st.exp = { k, d, a, left, total,            // 原有：地点、深度、行事、剩几个月、共几个月（= 节点数）
  plan,                                       // 原有：u[]、enc、cx 等预掷数（评价不再预掷：plan.rnd 不用了）
  seed,                                       // 出发时生成；节点 i 的引擎用 seed + i 播种（同种子同按键 → 结果逐轮一致）
  nodes: [ { t } ],                           // t: 'fight' | 'elite' | 'boss' | 'treasure' | 'herb' | 'home'；长度 = total
  ni,                                         // 当前节点序号（0 起）；= 已走完的节点数
  hp, rage,                                   // 气血（0～1，占上限的比例）、怒气（0～100），一路带着走
  bt: { fights, won, dead, fled, brk, pill, eliteWin, bossWin, ke, beike, kills: [foeId], mats: { core: { mu: 1 } } },
  pol }                                       // 'auto' | 'smart'：没人看着时（sim、速战、读档跳过）节点由 L.battleAuto 按它打
```

- `L.expNodes(st, k, d, a, len)` → 节点表；`L.expNodeFoes(st, e, i)` → 这一节点的敌人数组（见 3）。
- 每过一个月（`L.tick`）消费一个节点：节点还没打（界面没接管）就 `L.expNodeRun(st)` 用 `L.battleAuto(B, e.pol)` 打完；界面打完一场调 `L.expNodeDone(st, res)` 记下结果，然后照常 `onTick()` 过月。
- 倒下（`res.dead`）或撤（`res.fled`）：这一趟在本月结束（`e.left = 1`），结算照 §2.3 / §2.2。
- 评价：`L.expRating(e)` 按 §2.3（丁 / 丙 / 乙 / 甲 / 天 = 0～4），`expCalc` 的 `rating` 用它；`L.RATE_M` 不变。

### 2. 一场战斗（`B` 与结果 `res`，C1）

```
B = L.battleNew(st, foes, seed, opt)          // opt: { hp, rage, pills, pact, ult0, first }，hp / rage 为一路带来的值
ev = L.battleStep(B, { ult, pill, flee })     // 推进一轮，返回事件数组：
     { t: 'hit'|'skill'|'ult'|'charge'|'heavy'|'break'|'shield'|'ke'|'beike'|'chain'|'dead'|'pill'|'stun'|'dot'|'heal'|'crit'|'miss',
       who: 'me'|foe 序号, id: 招式 id, n: 招名, dmg, el, hp, sh, … }
res = L.battleAuto(B, policy)                 // 'auto'：怒气满就放；'smart'：留绝招破招、血少吞丹
res = L.battleResult(B)
  = { win, dead, fled, hp /*0～1*/, rage, rounds, brk /*破招次数*/, ke, beike, pill, kills: [foeId], elite, boss,
      mats: { core: { mu: 1 } },              // 精英 / 首领掉的灵核（§6.2）：C2 入库
      used: { 招式id: 次数 } }                // 熟练：C1 自己调 L.addMastery
```

- 我方属性：`L.btMe(st)` → `{ atk, hpMax, el /*护体*/, skills: [战技, 器技, 秘术], ult, pas }`；招式由 `L.artSkill(st, id)`、`L.gearSkill(x)` 给（C1，写在 `battle.js` 里，不改 `gear.js`）。
- 法宝上会影响战斗的字段（C2 写进法宝对象，C1 只读）：`x.el`（淬灵后的五行，空则用底子的）、`x.star`（0～3）、`x.gold`（金词条 id）、`x.aff`（词条 id 数组）、`x.edge`（开锋，P1）。
- 战斗类词条 id（C2 在 `L.AFFIX` 里用这些名字，C1 的引擎按名字生效）：`huixin` 会心、`lianji` 连击、`xixue` 吸血、`pozhao` 破罩、`xiansheng` 先声、`xushi` 蓄势、`fengsheng` 逢生、`yinbao` 引爆、`jianren` 坚韧、`fanzhen` 反震、`tiebi` 铁壁、`huiqi` 回气、`jixing` 疾行、`yangshang` 养伤；`ke_jin` 等改为“打该系 +20%”；`cangfeng` 被克不减伤。金词条 id：`fenguang` 分光、`huixiang` 回响、`budong` 不动、`jieshi` 借势、`shisha` 嗜杀、`liaoyuan` 燎原、`guiyi` 归一、`huajin` 化劲。

### 3. 怪物表（C1）

- `L.FOES[id] = { id, n, el, kind: 'mob'|'elite'|'boss', art /*画法*/, trait }`；`L.CELL_FOES[k][d] = { mobs: [id], elite: id, trait, sig /*本地招牌*/, core /*灵核五行*/ }`。
- `sig` 写成 `{ kind: 'art', id: 'z_qingteng' }` 或 `{ kind: 'gear', base: 'w1_0', el, star }`，C2 的掉落表直接读它当第 2 格。

### 4. 归途翻牌（C2 提供，C1 调用）

```
cards = L.tripLoot(st, trip)                  // C2：算掉落、保底、心愿，并且直接发放（入库 / 进 st.gear.pend），返回翻牌列表
  trip = { k, d, a, rating, won, eliteWin, eliteId, eliteEl, boss: bool, bossFirst: bool, treasure /*宝节点数*/,
           seq /*第一世第几趟，1 起*/, must: [ { kind: 'gear', base, el } | { kind: 'art', id } | { kind: 'gear', minStar: 1 } ], recall }
  cards[i] = { kind: 'gear'|'art'|'frag'|'core'|'ore'|'pill'|'herb'|'treasure'|'rune'|'plan'|'mat', item /*发放后的对象*/, tier, stars, el, wish: bool, value /*排序用*/ }
showLootFlip(cards, done)                     // C2 界面：翻牌仪式；C1 的结算卡在评价章后调它，done() 后接“你变强了”
L.matsAdd(st, mats)                           // C2：战斗掉的灵核等入库（st.mats.core）
```

- `trip.must`：第一章保底脚本由 C1 定（§7.3：第 1 趟精钢剑、第 2 趟《裂金斩》、第 3 趟第一件 ★），C2 必须把它们排进牌里。
- C1 的兜底：没有 `L.tripLoot` 时按原 `o.drops` 发放并用原光柱揭晓；没有 `L.matsAdd` 时 `st.mats.core[el] += n`。
- 灵石、灵草、灵矿、修为这些每趟都有的仍由 C1 的 `expCalc` 算（不占牌），结算卡牌上方一行给。
