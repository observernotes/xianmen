# 废柴仙途

一款像素风个人修仙游戏。被宗门逐出、被当众退婚的杂灵根废柴，捡到一枚住着老爷爷的戒指，从此一路逆袭到白日飞升。

系统极简、只靠点按，修仙的爽点一个不少：灵根觉醒、三年之约、渡劫突破、越级挑战、三宗争徒、宗门晋升、天骄榜打脸、白日飞升、转世重修。

单文件网页，打开 `dist/index.html` 即可游玩（手机、电脑都行），进度自动保存在本机。

## 怎么玩

第一次进游戏，戒中老祖会像秘书一样一步步带你：一次只说一两句，说话时游戏暂停，每句都带具体数字（“战力 10 → 13，胜算 3% → 16%”），说完立刻让你动手。坊市、宗门这些入口一开始是灰的，用得上时才解锁，老祖会在那一刻告诉你它能干什么。

修为条下面一排是**核心数值**：修炼/周天、战力、灵石/周天，最右边是**下一件大事**的倒计时——开局是“约战 N周天 · 胜算 X%”（三年之约），之后是天骄论道、九宗会武。点前三格能看到数值由哪些加成组成、怎么提升；点最右边能看到双方战力和“老祖锦囊”（每条办法能把胜算提到多少）。

三年之约（第 36 个周天开打，对手战力 125，筑基前老祖借你 2.5 倍战力）按 `tools/sim.js` 200 局模拟：只打坐胜算约 21%，懒散玩家（每届论道前出门两趟、不闭关、功法只照掉落卡换）约 67%，跟着引导循环历练、闭关、升级、换克制的战技约 94%。

| 按键 | 做什么 |
| --- | --- |
| 历练 | 选地点 × 深度（外围/腹地/禁地）× 行事（斩妖/寻宝/采药），确认页写着预计评价和负伤风险；回来盖印评价天甲乙丙丁，奖励随评价翻倍或打折 |
| 洞府 | 闭关（4 周天修炼翻倍，花灵石，连着闭关会疲劳）、服丹疗伤；升级聚灵阵（修炼速度）、灵田（灵石和灵草）、丹炉、洞府（寿元）；进炼丹房炼丹 |
| 宗门 | 筑基后开放，三大宗门来抢人；用贡献晋升身份，从外门弟子一路做到宗主，宝库换功法法宝；九宗排名与灵脉 |
| 坊市 | 买破境丹、延寿丹，寻宝开法宝功法，孵灵兽蛋（第一次历练回来后开放） |
| 人物 | 属性、**功法**（三槽：心法 / 战技 / 秘术，点槽再点一门就换上）、人物羁绊、成就称号、宿敌与天骄榜、地图首领、前世记录 |

## 内容

- **奇遇事件 327 个**（基础 122 + 扩展包 205：秘境、宿敌与新秀、坊市、宗门、人物委托、灵宠洞府历法、奇遇链、主线补段）：洞府、历练随时触发，大多有 2～3 个选项（救不救、抢不抢、信不信），带成功率或交手胜负。扩展包里用到还没做的系统（长老人脉、因果、灵宠名册…）的事件先不出现，系统接上就自动上线，眼下上线 165 个（`node tools/check_events.js report`）。
- **功法 36 门**：心法管修炼，战技管战力并定攻击属性，秘术给特效；装着就涨熟练（入门→小成→大成→圆满→化境），圆满留一份“融会”；两门同属有共鸣，特定组合有 18 条有名的共鸣，凑齐时揭晓并记进图鉴（跨世保留）。来自寻宝、历练（血煞秘境掉魔道功法）、宗门宝库（各宗独有四门）、首领首杀、奇遇与主线；重复得到熟练 +20，仙神阶的两门要集齐三片残篇。
- **五行**：金克木、木克土、土克水、水克火、火克金。地图、宿敌、首领、九宗都有属性；战技克制此地历练分数 +8、克制对手战力 ×1.15，被克反之。地图属性去过才知道，对手属性交过手才知道。
- **主线 13 章**：每踏入一个大境界揭开一段——戒中老祖是谁、天剑宗的镇宗剑诀从哪来、神秘黑衣人墨无痕为何而来，直到渡劫前的诀别。
- **人物羁绊**：医修、魔门圣女（二选一可结为道侣，双修加速）、剑痴楚狂、落魄丹师葛老、化形灵狐白小九、黑衣人墨无痕。好感 60 成为知己，各有永久加成。
- **宗门之争**：天下九宗排座次，每 24 周天一届九宗会武，你代表本宗一路挑战，目标天下第一宗；灵脉争夺、挖墙脚、细作、正魔大战等宗门事件。
- **炼丹**：灵草炼培元丹、聚灵丹、延寿丹、洗髓丹（提升灵根）、九转金丹（突破必成），成丹分下中上极四品。
- **地图首领 11 个**：每张地图打赢 3 次后首领现身，掉落天材地宝、专属法宝和称号。
- **成就与称号 39 项**，称号可佩戴。

其余交给时间：打坐自动涨修为，小境界自动提升（每层战力 ×1.5）；历练途中修炼减半，所以“出门拿资源”和“在家闭关”要取舍。在洞府打坐时脚下的吐纳环会蓄满，点自己立得 1 周天修为。洞府门口有时来访客（画面里的“！”）。修为条变成金色时点它，冲击大境界（破境丹每枚 +15%，一次最多 3 枚；金丹起要渡雷劫）。三年之约之后，每 12 周天举行一届天骄论道，打赢了排名飙升。底部的札记栏是本章的任务，做完即领。

境界：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升。境界越高寿元越长，但一个周天流逝的年数也越多。寿元将尽时突破有绝境加成；真的坐化了就转世重修，天赋三选一，下一世更快。

按 `tools/sim.js` 的引导型玩法，第一世约 610～780 周天飞升（中位数约 727；1 倍速一周天 5 秒，可开 2 倍、4 倍速）。功法系统关掉（`node tools/sim.js all 200 noarts`）时中位数约 882：功法让化神以后的境界快了两到三成。前期境界仍比设计目标快、后期仍偏慢，余量留给法宝等后续系统（见 `docs/SYSTEMS.md` §18）。

## 安卓

`dist/xiantu.apk` 是离线单机安卓安装包（Android 5.0 及以上），游戏全部内置，不需要联网，存档保存在手机本地。

重新打包：

```
sudo apt install android-sdk-build-tools android-sdk-platform-23 apksigner zipalign default-jdk
bash tools/build_apk.sh
```

签名文件默认是 `android/release.keystore`（不进仓库）。以后更新版本要用同一个签名文件，才能覆盖安装、保留存档。

## 开发

```
src/logic.js      逻辑入口（node 用）：按 MODULES 顺序把 src/logic/*.js 装到同一个 L 上，浏览器和 node 共用
src/logic/        逻辑模块：core 参数与公式、事件能力登记 → stats 倍率汇总 → items → arts 五行与功法 → home → npc → rivals → sect → expedition
                  → cultivation → market → alchemy → events-engine → quests → meta → save（存档迁移）→ tick
src/events.js     奇遇与主线事件数据（tools/check_events.js 校验）
src/content/      事件扩展包（events-engine 的 L.CONTENT_FILES 列出加载顺序，node 与 dist 都加载）；
                  事件用到的每个写法都要有系统用 L.supportFx / supportElig / supportTrigger… 登记过才会出现
src/art.js        像素美术：精灵、洞府场景、历练场景（全部代码绘制）
src/ui/           界面片段（共用一个作用域），按 tools/build.py 的 UI_PARTS 顺序拼接
src/template.html 样式与页面骨架
tools/build.py    裁剪像素字体并打包成单文件 → dist/
tools/sim.js      数值模拟：node tools/sim.js（三种策略 × 200 种子汇总）；node tools/sim.js guided 1 v 7（单局逐 12 周天）；
                  加 noarts 关掉功法系统，与默认对照量 SYSTEMS §18 的预算
tools/check_events.js 事件校验；加 report 列出上线 / 闸住的数量与闸住最多的键
tools/preview.js  美术预览：渲染 tools/preview.html 里的精灵与场景
tools/shot.js     Playwright 冒烟测试与截图
tools/longrun.js  机器人通过界面完整玩一世（掉落卡点【换上】、每 24 周天在功法页点“荐”），检查全程无报错且飞升
tools/guide_test.js 按真实玩家的点法走一遍新手引导，逐步截图
tools/content_test.js 奇遇、炼丹、首领、会武、人物分页的界面测试
```

构建：

```
pip install fonttools brotli
python3 tools/build.py
```

## 字体

像素字体使用 TakWolf 的 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font)（SIL Open Font License 1.1，见 `tools/FONT-LICENSE.txt`）。打包时裁剪为游戏所需字符与 GB2312 一级常用字，并按 OFL 要求改名为 XPixel。
