# HD-2D 样张（Pixel 7 竖屏，1082×2202）

全部由游戏本体截出：`node tools/hd2d_shots.js`（`*_before` = `?hd=0` 原画面，`*_after` = `?hd=3` 极致档，`*_cmp` = 左右对比）。默认档（2）与 3 档的差别只在光与粒子的平滑程度。

| 画面 | 文件 | 看点 |
|---|---|---|
| 洞府主界面（黄昏） | `home_*` | 远山虚化、落日光柱与辉光、人物轮廓光、前景云海、界面皮肤 |
| 洞府（正午 / 夜） | `home_day_*`、`home_night_*` | 昼夜两套光：正午顶光；夜里月光 + 灯笼石灯的光晕 |
| 历练战斗（黑风岭） | `battle_*` | 落日主光、人物投影、风沙 |
| 历练战斗（后山野林） | `battle_forest_*` | 景深最明显的一张：林海全虚、晨光光柱、投影 |
| 剧情对话 | `talk_*`、`talk_cast_*` | 气氛层（辉光、浮尘、暗角）、立绘 2 倍密度 |
| 面板 | `panel_*`、`panel_exp_*` | 卷轴木轴、宣纸纤维、3 倍密度九宫格与角花、按钮高光 |
