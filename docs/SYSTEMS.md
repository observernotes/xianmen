# 《废柴仙途》核心系统设计（SYSTEMS v2）

> 基线是 `docs/DESIGN.md` v1。玩家反馈：系统简化过头、可玩性不够、内容太少。本文在 v1 的循环（历练 / 闭关 / 论道 / 突破）之上加**构筑层、发现层、收集层、经营层**。v1 §3 的公式除本文 §18 明确替换的以外继续有效。内容表（每门功法、每件法宝的名字和数值）在 `docs/CONTENT.md`。
> 代码对齐：以 `redesign` 分支的 `src/logic.js` 为准，本文用到的现有名字：`st.p.a/w/pet`、`st.home`、`st.meta`、`st.best`、`L.giveItem`、`L.expExtra`、`L.expParts`、`L.RECIPES`、`L.AUCTION`、`L.rollTasks`、`L.BUILDS`、`L.btParts`。

## 0. 总则

**深度从哪来**（对照游戏发展国：很多小系统互相咬合，但每次只点一两下）：

1. **五行**是把所有系统串起来的一根线：功法、法宝词条、灵宠、地图、对手、药引、灵田作物都带五行属性，克制与相生到处生效。
2. **试出来的组合**记进图鉴、跨世保留：地点×行事相性（已有）、功法共鸣、丹方、灵宠进化、人物喜好、对手属性。共 6 张发现表，约 150 个格子。
3. **会成长的名册**：功法（熟练度）、法宝（强化）、灵宠（等级/进化/岗位）、徒弟（境界/差事）、洞府（地块）。
4. **每隔几分钟一次取舍**：历法和天下大势让“现在最划算的事”一直在变；槽位、地块、同伴位、丹毒、秘境气血都是不够用的资源。
5. **不做的事**：背包整理、地图走格子、手动战斗、拖拽摆放。所有新系统的操作都是“点一个槽 → 在列表里点一项”或“二选一/三选一”。

**交互硬规则**：任何系统的常用操作 ≤ 2 次点击；列表按“推荐”排序，第一项永远是老祖推荐的（标“荐”并给一句带数字的理由）；新掉落只弹一张“换上 / 不换”卡，不换的自动折成材料。

**解锁节奏**（每半个境界开一个新东西，老祖讲解一次；转世后全开）：

| 时点 | 解锁 |
|---|---|
| 炼气初期 | 历练、聚灵阵、功法·心法槽 |
| 炼气中期 | 闭关、灵田（1 块地，只能种灵草）、坊市轮换货架 |
| 炼气后期 | 丹炉（基础丹方）、功法·战技槽、五行克制（第一次遇到被克的图时讲） |
| 炼气圆满 | 法宝·兵器强化（器炉可建） |
| 筑基初期 | 宗门与任务板、灵宠、历法与天下大势、行情（出售） |
| 筑基中期 | 秘境、法宝·法衣槽、灵田作物与药引、丹方试炼 |
| 筑基后期 | 洞府地块（第 4 块起要选）、阵法切换 |
| 金丹 | 天劫抉择、功法·秘术槽、拍卖竞价、灵宠第二只与岗位、连续历练 |
| 金丹后期（真传） | 宗门职司、第一个徒弟 |
| 元婴 | 法宝·饰品槽、灵宠进化二阶、同伴、道侣、人脉（长老支持） |
| 化神 | 打造专属法宝（器方）、第二个徒弟、新秀挑战 |
| 炼虚以后 | 第二阵法位、宗主建设、第三个徒弟、三人会武 |

**资源一览**（HUD 只常驻灵石和寿元；其余在用到它的面板里显示）：灵石、灵草、破境丹、天材地宝、宗门贡献（已有）；新增 **灵矿**（强化/打造）、**兽粮**（喂灵宠）、**药引**五种（火/冰/雷/木/魂，炼丹）、**秘境令**（进秘境，最多持 3）。

## 1. 五行（新，贯穿）

- 五行：金 木 水 火 土；另有“无”（不参与）。**相克** 金→木→土→水→火→金；**相生** 木→火→土→金→水→木。
- 玩家的**攻击属性** = 装备的战技的属性（没装战技为无）。地图属性：后山野林 木、黑风岭 金、落日古墓 土、万妖山脉 木、血煞秘境 火、上古剑冢 金、九幽魔渊 水、东海龙宫 水、天外星墟 火、太古仙府 土、混沌裂隙 无。宿敌与首领各有属性（见 CONTENT）。
- 效果：历练分数 克制 +8 / 被克 −8；对决战力 克制 ×1.15 / 被克 ×0.87。只算攻击属性一方向（对手的战技克你同理）。
- 发现：地图属性第一次去之后显示；对手属性第一次交手后显示（记 `st.meta.elem`）。出发页和锦囊在已知时直接写“你的火系战技克此地（金）：分数 +8”，未知写“？”。
- 老祖：第一次带着被克的战技打开某图的确认页时讲解一次（“金克木，你这手木系的剑法在黑风岭要吃亏：分数 −8。换一门战技，或者认了。”）。

## 2. 功法（保留并加深：三槽 / 熟练 / 共鸣）

**目的**：构筑与收集的主轴；“换一门功法就翻盘”的爽点；长期目标（把收集到的功法练到圆满）。

**规则**

- 三个槽：**心法**（修炼倍率，炼气初期）、**战技**（战力倍率 + 攻击属性，炼气后期）、**秘术**（功能性效果，金丹）。每门功法有：类别、阶（1～6，沿用 黄/玄/地/天/仙/神）、五行、一条特效。全表 36 门（CONTENT §2）。
- 倍率：心法沿用 `L.ARTS[tier].m`（1.15/1.35/1.6/1.9/2.25/2.7）；战技 `[1.10, 1.20, 1.32, 1.45, 1.60, 1.80]`；秘术没有裸倍率，只有特效（例：御风诀“历练时长 −1 周天”、敛息术“负伤风险减半”、天眼通“秘境多看一扇门”）。
- **熟练度**：装备着的功法每周天 +1 点（心法在闭关中 +2；战技每趟斩妖历练另 +2；藏经阁每级 +10%）。五级：入门 / 小成 / 大成 / 圆满 / 化境，所需累计点数 `[0, 12, 36, 80, 150] × (1 + 0.5 × 阶)`。效果：该功法的“超出 1 的倍率部分”和特效数值 ×`[1, 1.1, 1.2, 1.3, 1.45]`。练到**圆满**得一份永久的“融会”：心法 +1.5% 修炼、战技 +1.5% 战力、秘术两者各 +0.75%，卸下也保留，全功法合计上限 +30%。
- 换功法免费，但心法更换后 2 周天内修炼 ×0.5（“转修”），防止来回切。战技、秘术即时生效。
- **共鸣**（发现表，18 条有名字的 + 通用规则）：
  - 通用：三槽中两门同属性 → 修炼、战力各 +4%；三门同属性 +10%。心法**生**战技（如木心法 + 火战技）→ 战技倍率部分 +10%。
  - 有名共鸣：特定两门或三门同时装备触发（例：《青木长生功》+《回春剑诀》=「生生不息」负伤恢复 ×2、寿元流逝 −10%）。第一次凑齐时横幅揭晓并记入 `st.meta.combo`，之后在功法列表里以连线标出。未发现的在图鉴里显示“？+？”，藏经阁每级揭示一条提示（“据说某两门木系功法同修有奇效”）。
- 获得：寻宝、历练掉落（现有功法掉落改为掉具体的一门）、宗门宝库（各宗独有 4 门）、首领、秘境秘藏、奇遇、拍卖。重复获得 → 该功法熟练 +20 点（不浪费）。
- 残篇：仙阶、神阶功法以 3 片残篇形式掉落，集齐自动合成。

**界面**：【人物】→ 功法页，三个大槽 + 下方已有功法列表（按“换上后修炼/战力变化”排序）。点槽 → 点功法，完成。列表项显示：阶色、五行图标、熟练度条、与当前另两槽的共鸣标记。

**老祖**：得到第二门心法时讲（“功法不止一门。这门修炼 ×1.35，比你现在的多 **+{n}/周天**；练久了还有熟练。”）；第一次触发通用共鸣时气泡；战技槽、秘术槽解锁时各一次。

**联动**：五行（攻击属性）、藏经阁（熟练速度、提示）、徒弟（可传授自己圆满的功法）、轮回（带走一门圆满功法，下一世从小成起）、宗门（独有功法）、秘境“悟”房间（熟练 +10）。

**替换**：`st.p.a / st.p.an` → `st.arts = { own: { id: 熟练点数 }, slot: [心法id, 战技id, 秘术id], swapAt }`；`L.gain/L.power` 里的 `L.ARTS[p.a].m` 改调 `L.artCul(st)`、`L.artAtk(st)`；`L.giveItem(st, 'a', tier)` 改为按阶从未拥有的功法里抽一门（都有了则给熟练）。

## 3. 法宝与炼器（保留并加深：三槽 / 强化 / 词条 / 打造）

**目的**：掉落揭晓的爽点从“阶数 +1”变成“这件带的词条正好是我要的”；灵矿成为稳定去处；首领材料有用。

**规则**

- 三槽：**兵器**（战力倍率，沿用 `L.WEAPONS[tier].m`，开局）、**法衣**（护体：历练分数 +1.5×阶、负伤周天 −1（阶≥3）、天劫承劫 +3×阶，筑基中期）、**饰品**（按饰品种类给 修炼 +3%×阶 / 灵石收入 +4%×阶 / 奇遇把握 +1%×阶 / 寿元 +2%×阶 之一，元婴）。阶 1～7。
- **词条**：每件掉落随机 1 条（阶 ≥4 时 2 条），从 16 条里抽（CONTENT §3.4，例：「锋锐」斩妖分数 +5、「聚财」历练灵石 +12%、「克木」对木属性战力 +10%、「护主」丁等不负伤（每 12 周天一次））。首领专属与打造品的词条固定。
- **强化**：+0～+9，每级使该件主属性的“超出部分” +6%（兵器 +9 ≈ 主倍率再 ×1.3 左右）。花费灵矿 `8 × 1.6^级 × 1.5^阶` 与灵石（同数值 ×5）。成功率 `[100,100,100,90,80,70,60,50,40]%`，失败不掉级、不碎，下次 +10%（保底）。换装备时强化等级**继承一半（向下取整）**，所以强化不是白花。
- **重铸**：花 1 个天材地宝重抽一条词条（二选一保留）。
- **打造**（化神，器炉 5 级）：12 张器方（CONTENT §5），用首领材料 + 灵矿打出固定词条的专属法宝；器方来自首领首杀、秘境、拍卖、葛老/器堂。
- **不做背包**：新掉落弹对比卡（主属性、词条、强化继承后的结果、战力变化），【换上】或【熔炼】；熔炼得灵矿 `4 × 2^阶`。同时可点【锁定当前】让以后更低阶的自动熔炼不再弹卡。
- 灵矿来源：历练（斩妖 ×1.5，金属性地图 ×2）、熔炼、秘境战斗房、坊市轮换、宗门器堂。每趟基础量 `(1 + k) × (1 + 0.5d) × 评价倍率`。

**界面**：【人物】→ 法宝页，三格 + 每格下【强化】按钮（点一下强化一次，长按连强）；【洞府】器炉里是打造列表。

**老祖**：第一次掉到带词条的兵器时讲对比卡；炼气圆满讲强化（“灵矿别攒着。强化 +1：战力 **{a} → {b}**，约战胜算 **{p} → {p'}**。”）。

**替换**：`st.p.w / wn` → `st.gear = { w: {id, tier, plus, aff: [..], fail}, r: {...}|null, o: {...}|null }`；`L.giveItem(st, 'w', tier)` 返回待决定的掉落，UI 走对比卡，sim 用“主属性更高就换”。

## 4. 灵宠（保留并加深：名册 / 等级 / 进化 / 岗位）

**目的**：养成线和“进化揭晓”的爽点；闲着的灵宠在洞府干活，名册越大越有用。

**规则**

- 12 个基础种（CONTENT §4），每种有：五行、类型（战 / 护 / 灵 / 寻）、基础战力倍率（沿用 `L.PETS` 的阶：1.2～3.0 由“种的品阶 + 进化阶段”决定）、一个天赋。
- 名册上限：筑基 1、金丹 2、元婴 3、合体 4。**出战** 1 只（其战力倍率与天赋生效）；其余每只占一个**洞府岗位**。
- 岗位（一只一岗，类型对口效果 ×1.5）：守田（灵田产量 +15%）、看炉（成丹率 +6%）、护阵（聚灵阵效果 +5%）、觅食（每周天 0.5 兽粮 + 小概率叼回药引/灵矿）、巡山（坏访客与盗贼事件 −50%）。
- **等级** 1～10：喂兽粮，每级需要 `6 × 1.5^级 × 品阶`；出战灵宠每趟历练另得 1 级经验的 10%。每级使其倍率的超出部分 +5%、岗位效果 +4%。
- **进化**：5 级时二选一分支进化（换外形、名字、天赋、品阶 +1）；10 级时“觉醒”（不分支：天赋升级、品阶再 +1、外形加光环）。分支条件是“喂一份指定五行的药引 / 在指定属性的地图历练过 3 趟 / 好感满”等（进化表是发现表：未试过的分支显示“？”，条件满足时灵宠头上冒光）。共 12 基础 + 24 进化形态。
- **好感**（0～5 心）：出战、喂食、事件加；每心 +2% 其全部效果；5 心解锁“挡劫”（天劫可用）和不会出走。连续 24 周天既不出战也没岗位会掉好感。
- 获得：灵兽蛋（坊市/拍卖/秘境，种按蛋的属性随机）、采药历练偶遇（该地图对应的种）、奇遇、宗门（御兽相关任务）。名册满时新灵宠可【放生】（得兽粮）或【替换】。
- 兽粮来源：灵田作物“灵谷”、觅食岗位、斩妖历练少量、坊市。

**界面**：【洞府】→ 兽栏：灵宠卡片横排，点卡 → 【出战 / 派岗（弹 5 个岗位图标）/ 喂食（长按连喂）】。进化条件满足时卡片发光，点一下进化（二选一卡）。

**老祖**：第一只灵宠（现有主线“认主”）；第二只时讲岗位；第一次可进化时讲。

**替换**：`st.p.pet = {tier, name}` → `st.pets = [{ sp, form, lv, xp, heart, job }]`，`st.petOut = 索引`；`L.PETS[...]` 的倍率查找改 `L.petAtk(st)`。

## 5. 炼丹（保留并加深：药引发现 / 丹毒 / 自动续炼）

**目的**：把“灵草 → 点按钮”变成一张 5×5 的发现表；丹毒让“嗑多少药”成为取舍。

**规则**

- 基础丹（丹炉 1 级，不需药引）：培元丹、破境丹、疗伤丹（新，专门疗伤，破境丹不再兼任）。
- **药引丹**：选两味药引（可相同）+ 灵草 → 15 种组合对应 15 种丹（CONTENT §5.1）。没试过的组合显示“？”，点【试炼】消耗材料：成则揭晓并永久记入 `st.meta.recipe`（跨世保留）；不成（该组合无丹的情况不存在，15 格全有丹）只看成丹率。葛老、丹经残页、丹霞谷任务会直接告诉你某一格。
- 已知丹方列表一键【炼制】；可勾“自动续炼”（材料够就每 3 周天自动炼一炉指定的丹，上限 3 种）。
- 成丹率与品质沿用现有（`L.alchRate`、`L.QUAL`），看炉灵宠、丹堂职司、炼丹阵加成。
- **丹毒**（0～100）：每服一枚增益类丹药 +15（上品 +10，极品 +5）；每周天 −2；灵泉每级再 −0.5。丹毒 > 60 时新服丹药效果减半，> 100 不能服。突破时服的破境丹每枚 +10。界面在状态栏用一个小葫芦显示。
- 丹药按**用途分三类**，界面分页：修炼类（聚灵丹、悟道丹…）、战斗类（爆气丹、金刚丹，下一场对决或下一趟历练生效）、根基类（延寿、洗髓、九转、驻颜…不计丹毒但有每境界次数上限）。
- 大事前老祖锦囊会把“服一枚爆气丹：胜算 p → p'”列为候选。

**界面**：【洞府】→ 炼丹房：上半是 5×5 药引格（对称，实际 15 格），已知的显示丹药图标；下半是当前选中丹方与【炼制】。

**替换**：`L.RECIPES` 扩成 18 条并加 `yin: [a, b]`；新增 `st.toxin`、`st.mats.yin`；`L.heal` 改用疗伤丹（没有疗伤丹时仍可用破境丹，效果相同，保留旧行为作为兜底）。

## 6. 洞府：地块、建筑、灵田、阵法

**目的**：经营层。地块比建筑少 → 选哪几样；灵田种什么跟着当前需求变；阵法是“家里的姿态”。

### 6.1 地块与建筑

- 洞府等级决定地块数：`3 + floor(洞府等级 × 5 / 12)`（0 级 3 块，12 级 8 块）。聚灵阵固定占 1 块且不可拆。
- 建筑 11 种（各有等级，价格公式沿用“`base × grow^lv`”）。建造 = 点空地块 → 点建筑；拆除返还累计花费的 50%（保留等级记录，重建从一半等级起）。

| 建筑 | 效果（每级） | 上限 | 解锁 |
|---|---|---|---|
| 聚灵阵 | 阵法强度（见 6.3），默认聚灵：修炼 ×1.08^lv | 30 | 开局 |
| 灵田 | 田数 `1 + floor(lv/4)`（上限 6 块），产量 +8%/级 | 20 | 炼气中期 |
| 丹炉 | 成丹率 +3%，突破 +1%，丹方等级门槛 | 20 | 炼气后期 |

## 7. 历法与天下大势

**目的**：让“现在做什么最划算”不断变化；给世界时间感；所有周期性活动放进一张历。

- **四季**：12 周天一轮，周天数 `t % 12`：1～3 春、4～6 夏、7～9 秋、10～0 冬。春：灵草类作物旺、访客 +30%；夏：秘境开放（4～9）、兽类地图灵石 +15%；秋：灵稻旺、坊市行情偏高；冬：闭关倍率 +0.2、年末（`t%12 = 0`）天骄论道。场景美术已有四季，直接对上。
- **固定历**（24 周天一个大周期，沿用代码里的常数）：论道 `t%12 = 0`；拍卖会 `t%24 = 8` 起 6 周天；九宗会武 `t%24 = 18`；宗门任务板与坊市货架在每届论道后刷新；秘境在每个夏季开放。
- **天下大势**：每轮 `t%12 = 2` 时 60% 概率发生一件，持续 6～10 周天，在场景右上角以一枚小牌显示，点开看效果。12 种（CONTENT §8）：兽潮（斩妖灵石 ×1.8，丁等概率上升）、灵气潮汐（修炼 +30%）、丹道大会（丹药卖价 ×2，成丹率 +10%）、矿脉现世（指定地图灵矿 ×3）、魔劫（魔道地图推荐战力 ×1.3、奖励 ×1.6）、流星雨（天外陨铁：寻宝掉落 +1 阶概率翻倍）、大旱（灵田 −40%）、仙府现世（开一次特殊秘境）、商路断绝（坊市涨价 30%）、名师讲道（指定宗门或地点闭关 ×1.5）、通缉令（击败指定路人得赏金）、太平无事。
- 老祖在大势开始时气泡一句“该干什么”：例“兽潮来了，这 8 个周天斩妖灵石多八成——不过评价会低一档，量力。”

**界面**：场景左上“大事”牌保留倒计时；点开变成**年历**：一条 24 格的时间轴，标出论道、拍卖、会武、秘境、当前大势，各带倒计时。

## 8. 秘境（新：一局内的小冒险）

**目的**：一分钟内连续 6～8 次“贪不贪”的决定，是全游戏最密集的抉择；产出独有功法、器方、阵图、灵宠蛋。

- 进入：筑基中期解锁；夏季开放；消耗 1 枚秘境令（每个夏季送 1 枚，另可由任务、拍卖、坊市得到）。秘境主题 4 种轮换（剑气·金、百草·木、熔火·火、幽泉·水），主题决定敌人属性和秘藏池。
- 一局：层数 `6 + (r ≥ 4) + (r ≥ 6)`。带入**气血 100**（法衣每阶 +5，体修类功法另加）。每层给 2 扇门（有天眼通或白小九同行时 3 扇），门上画着房间类型，30% 的门是“？”。

| 房间 | 效果 |
|---|---|
| 战 | 掉气血 `clamp(30 × (层战力 / 我)^1.2, 5, 70)`；得灵石、灵矿，30% 掉法宝/功法 |
| 精英 | 气血损失 ×1.8，奖励 ×2.5，必掉一件 |
| 宝 | 70% 得掉落（药引、残篇、器方碎片…），30% 是陷阱 −20 气血 |
| 泉 | 气血 +30 |
| 奇 | 一个秘境专属奇遇（二选一，`where: 'realm'` 事件） |
| 悟 | 当前一门功法熟练 +10，10% 得残篇 |
| 商 | 用本局已得灵石换一件东西（三选一） |
| 守关（最后一层固定） | 相当于精英 ×1.3；过关开**秘藏**：三选一（该主题的独有功法 / 器方 / 阵图 / 灵宠蛋 / 天材地宝） |

  层战力 = `rec(当前最高已开地图, 1) × 1.22^(层−1)`；克制与被克照 §1。
- 每过一层弹一行：【继续深入】/【带着 N 件收获离开】。气血归零 = 重伤出局：本局收获丢 60%，负伤 4 周天。

**界面**：场景区换成秘境背景，下方两/三张门卡；点门 → 场景里 1 秒小动画 → 结果飘字 → 下一层。全程每层一次点击。

**老祖**：第一次进入讲三句（门、气血、见好就收）；气血 < 30 时气泡提醒“该走了，手里已经有 {n} 件”。

## 9. 天劫（突破的加深）

**目的**：金丹起的每次突破是一场小戏，有准备、有临场一次抉择、有“渡得多漂亮”的评价。

- 成功率仍按 v1 §3.8 的各项加成算出 `p`，再加**护劫手段**（每次渡劫各限用一次）：

| 手段 | 加成 | 代价 |
|---|---|---|
| 祭法宝 | +8% | 失败时兵器强化 −1 |
| 灵宠挡劫（5 心） | +10% | 该灵宠休养 12 周天（无效果） |
| 道侣护法 | +8% | 每境界一次；失败时道侣好感 −5 |
| 临阵吞丹 | 每枚 +10%（最多 2 枚，算在 3 枚上限之外） | 丹毒 +20/枚 |
| 渡劫阵 | +1%/聚灵阵级，上限 +15% | 需提前 3 周天布阵 |

- 流程：准备页勾选要**预先**用的手段 → 雷劫一道道落（道数 3～9），画面上“护体”条按预掷结果下降 → 在**倒数第二道之前**暂停一次：显示“护体还剩 x%，照这样下去{大概能过 / 悬 / 过不了}”，此时可以把还没用的手段补上（就是这一次临场抉择）→ 最后一道 → 结果。
  “大概能过 / 悬 / 过不了”是把预掷的随机数与当前 `p` 比较后给的带噪声的提示（80% 准）。
- **渡劫评价**：`余量 = p − 掷出的数`。余量 ≥ 0.5 完美，≥ 0.25 上，≥ 0.08 中，> 0 下。每次按 完美/上/中/下 得永久“道基” +3% / +2% / +1% / +0%（修炼与战力），金丹那一次同时定名“N 品金丹”（完美 = 一品…）。道基累计上限 +24%，显示在人物页。
- **心魔劫**（元婴、化神、合体）：雷劫前先过一问——从本世做过的抉择里挑一件（杀过的人、负过的人）让你再选一次；与当初一致 +5%，动摇 −5% 但消一份因果（见 §14）。内容在 CONTENT 的主线表。
- 失败规则不变（修为退到 70%、负伤 3）；筑基没有雷劫，仍是一次掷。

**替换**：`L.breakthrough(st, n)` 拆成 `L.tribStart(st, opts)`（预掷、返回每道雷的护体曲线和提示）与 `L.tribFinish(st, extraOpts)`；`L.btParts` 增加上表各项。sim 的 guided 策略：有就全用。

## 10. 坊市、行情与拍卖

- **货架**：6 格。3 格常驻（破境丹、寻宝、灵兽蛋），3 格每届论道后从池子里轮换（药引、灵矿、兽粮、秘境令、功法残篇、阵图、器方、法衣、作物种子、折扣 20%～40% 的常驻货）。每格限购 1～3 件。右上角写“N 周天后换货”。
- **行情**（筑基）：可出售 灵草、灵矿、兽粮、各类丹药。每种有一个价格指数 0.6～1.6，每 6 周天随机游走一步（±0.2），受季节和天下大势影响；界面上写“灵草 ×1.4 ↑ 高于平时”。【卖出一半】【全卖】两个按钮。基准价：灵草 = `2 × 2.6^r`、灵矿 = 灵草 ×3、破境丹 = 买价的 40%，其余丹药 = 材料基准价 ×1.5 × 品质倍率。这是炼丹、灵田的“变现”出口，也是丹霞谷路线的收入来源。
- **拍卖**（金丹，替换现有一口价）：每场 3 件。每件显示起拍价（约 12 周天收入）和**竞拍者**（60% 概率有一位有名字的对手或人物在场）。出价三档：【跟一口】起拍价 ×1.0，拿下概率 35%；【加价】×1.4，70%；【豪掷】×2.0，97%；有竞拍者时各 −15%。没拿下不花钱。**宿敌拍到的东西会生效**：他的战力永久 ×1.04，并在下次论道的台词里提起。同一场只能出手两次。
- 寻宝保底规则保留；寻宝的产出改为 §2、§3 的具体功法/法宝。

## 11. 宗门（加深：职司 / 人脉 / 宝库轮换 / 徒弟）

**目的**：宗门是第二条成长线，有自己的经济（贡献）、人（长老、同门、徒弟）和冲突。

- **任务板**（已实现的 8 类保留）增加 4 类：炼器（上交强化 +3 以上的法宝一件或灵矿 N）、驯兽（上交兽粮 N / 带指定属性灵宠出战一趟）、探秘（本季秘境到第 N 层）、讲法（以某门圆满功法讲道，花 2 周天，贡献 ×2 并使所有徒弟熟练 +）。
- **宝库轮换**：6 格，每届论道后换；本宗独有功法 4 门、独有法宝 3 件、独有阵图 1 张、独有丹方或器方 1 张按身份逐级开放（CONTENT §9）。贡献是唯一货币。
- **职司**（真传起，选一个，可在每届会武后改）：丹堂（成丹率 +8%，丹药出售 +20%，任务偏炼丹）、器堂（强化成功 +8%，熔炼灵矿 +30%）、战堂（斩妖分数 +5，论道奖励 +30%）、执法堂（坏事件 −，击败同门挑战者得贡献）、外事堂（坊市 −10%，拍卖拿下概率 +10%，人物来访 +）。
- **人脉**：每宗三位长老（CONTENT §9），各有一条 0～100 的支持度，来自对应类型的任务、事件抉择和送礼。支持 ≥ 40 得其小恩惠（如每届送一份材料），≥ 80 得其绝学（一门功法或器方）。**圣子之争、宗主之位**需要至少两位长老支持 ≥ 50（替换现有“贡献够了就升”里最后两级的条件之一）；三位长老的理念互相有冲突，讨好一位的事件选项常常得罪另一位（±）。
- **徒弟**（真传 1 人，长老 2 人，宗主 3 人）：
  - 来源：宗门每 24 周天送来 3 个候选（姓名、灵根 1～5 档、一个性情：勤勉 / 聪慧 / 莽 / 滑 / 痴 / 孤傲 / 仁厚 / 贪玩），三选一或都不要；奇遇里也能捡。
  - 成长：徒弟有自己的境界（小层序号 `di`），每周天成长 `0.02 × 灵根倍率 × (1 + 师父传授数 × 0.1)`，上限为师父的 `si − 4`。
  - **差事**（一人一事，点徒弟 → 点差事）：代师历练（每 6 周天带回当前可打地图一趟乙等收益的 30%）、打理洞府（被动灵石与灵田 +8%）、宗门当值（每周天贡献 = 0.3 趟任务）、闭门苦修（成长 ×2）。
  - **传授**：把自己已圆满的一门功法传给一个徒弟（一次性，花 2 周天）；徒弟战力因此提升，自己该功法熟练度不变，另得一次“教学相长”：该功法直接升到化境。
  - **出战**：九宗会武在宗主阶段改为三人战（你 + 两名徒弟各打一场，三局两胜），徒弟战力 = 其小层的基础战力 × 1.5 × (1 + 0.2 × 传授数)。
  - 事件：每个性情 2～3 个专属事件（闯祸、顶撞、突破、被挖角、出师）。徒弟境界到金丹可【出师】：离开名册，给一大笔贡献和一个“桃李”计数（轮回道果加分，下一世他会作为一位前辈人物出现一次）。
- 魔宗（魔门遗孤出身可入）与三正宗的差异、独有内容见 CONTENT §9。

**界面**：【宗门】四个分页：身份（含人脉三条）、任务板、宝库、门下（徒弟卡片 + 差事）。

## 17. 老祖如何介绍这些系统

沿用 v1 §4 的三通道。每个新系统**一次阻塞讲解 + 之后的气泡提醒**，讲解的句式统一为“这是什么（一句）→ 现在点哪里（高亮）→ 做了能涨多少（数字）”。问答优先级表（v1 §4.4）追加候选：有可进化的灵宠、有能强化且成功率 ≥ 80% 的法宝、有未发现但材料够的丹方、秘境开放且手里有令、当前大势对应的行动、拍卖里有能提升 ≥ 1 阶的拍品、有功法即将圆满（换下一门练）。锦囊候选追加：换成克制对手的战技、兵器强化到下一级、服爆气丹、灵宠升到下一级。
