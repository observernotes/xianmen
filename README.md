# 废柴仙途

一款像素风个人修仙游戏。被宗门逐出、被当众退婚的杂灵根废柴，捡到一枚住着老爷爷的戒指，从此一路逆袭到白日飞升。

系统极简、只靠点按，修仙的爽点一个不少：灵根觉醒、三年之约、渡劫突破、越级挑战、三宗争徒、宗门晋升、天骄榜打脸、白日飞升、转世重修。

单文件网页，打开 `dist/index.html` 即可游玩（手机、电脑都行），进度自动保存在本机。

## 怎么玩

| 按键 | 做什么 |
| --- | --- |
| 历练 | 御剑去各地打怪，带回灵石、修为、破境丹、法宝、功法，运气好能收服灵宠 |
| 洞府 | 升级洞府（加寿元）、聚灵阵（修炼速度）、灵田（灵石和灵草）、丹炉；进炼丹房炼丹 |
| 宗门 | 筑基后三大宗门来抢人；用贡献晋升身份，从外门弟子一路做到宗主，宝库换功法法宝；九宗排名与灵脉 |
| 坊市 | 买破境丹、延寿丹，寻宝开法宝功法，孵灵兽蛋 |
| 人物 | 属性、人物羁绊、成就称号、宿敌与天骄榜、地图首领、前世记录 |

## 内容

- **奇遇事件 112 个**：洞府、历练随时触发，大多有 2～3 个选项（救不救、抢不抢、信不信），带成功率或交手胜负。
- **主线 13 章**：每踏入一个大境界揭开一段——戒中老祖是谁、天剑宗的镇宗剑诀从哪来、神秘黑衣人墨无痕为何而来，直到渡劫前的诀别。
- **人物羁绊**：医修、魔门圣女（二选一可结为道侣，双修加速）、剑痴楚狂、落魄丹师葛老、化形灵狐白小九、黑衣人墨无痕。好感 60 成为知己，各有永久加成。
- **宗门之争**：天下九宗排座次，每 24 周天一届九宗会武，你代表本宗一路挑战，目标天下第一宗；灵脉争夺、挖墙脚、细作、正魔大战等宗门事件。
- **炼丹**：灵草炼培元丹、聚灵丹、延寿丹、洗髓丹（提升灵根）、九转金丹（突破必成），成丹分下中上极四品。
- **地图首领 11 个**：每张地图打赢 3 次后首领现身，掉落天材地宝、专属法宝和称号。
- **成就与称号 39 项**，称号可佩戴。

其余交给时间：打坐自动涨修为，小境界自动提升。修为条变成金色时点它，冲击大境界（金丹起要渡雷劫）。每 12 周天举行一届天骄论道，打赢了排名飙升。

境界：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升。境界越高寿元越长，但一个周天流逝的年数也越多。寿元将尽时突破有绝境加成；真的坐化了就转世重修，天赋三选一，下一世更快。

按默认节奏，第一世约 210～280 周天飞升（1 倍速约 20 分钟的修炼时间，加上奇遇、对决和剧情，一世大约玩 40 分钟以上；可开 2 倍、4 倍速）。

## 开发

```
src/logic.js      纯逻辑（数值、境界、历练、宗门、论道、事件引擎、炼丹、首领、成就），浏览器和 node 共用
src/events.js     奇遇与主线事件数据（tools/check_events.js 校验）
src/art.js        像素美术：精灵、洞府场景、历练场景（全部代码绘制）
src/ui.js         界面、场景动画、音效、存档
src/template.html 样式与页面骨架
tools/build.py    裁剪像素字体并打包成单文件 → dist/
tools/sim.js      数值模拟：node tools/sim.js <种子> [v]
tools/preview.js  美术预览：渲染 tools/preview.html 里的精灵与场景
tools/shot.js     Playwright 冒烟测试与截图
tools/longrun.js  机器人通过界面完整玩一世，检查全程无报错
tools/content_test.js 奇遇、炼丹、首领、会武、人物分页的界面测试
```

构建：

```
pip install fonttools brotli
python3 tools/build.py
```

## 字体

像素字体使用 TakWolf 的 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font)（SIL Open Font License 1.1，见 `tools/FONT-LICENSE.txt`）。打包时裁剪为游戏所需字符与 GB2312 一级常用字，并按 OFL 要求改名为 XPixel。
