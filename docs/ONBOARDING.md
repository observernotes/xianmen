## 2. 原则

1. **一次只教一件事。** 新系统解锁 = 老祖一段话 + 一个高亮的动作 + 一个小目标（札记最上面一行“【新】……”）。
2. **掌握了再开下一样。** 下一个系统要等：① 上一个系统的“掌握信号”（用过 N 次 / 达成某结果，见 §3 的“掌握”一列；玩家不理它，过了“最多等”也算），② 离上一次解锁的最短间隔。子项（已有系统里多一样，例如历练多了采药）只等父系统开、只占短间隔，用一条气泡宣布，不暂停。
3. **没开的东西界面上直接不出现**——底栏入口、分页、按钮、HUD 数值格、角标、场景物件、问老祖的建议、札记小任务、玩法指南的段落、坊市货架格、洞府里的“未开”地块都不画，而不是灰着锁着摆在那。逻辑层也一样（sim 里同样开不了）。
4. **已经发生了的不装作没有**：突破、三年之约、入宗、渡劫、拿到灵宠、收了徒弟、送过礼——这些一发生，对应系统立刻解锁（force），不等间隔。
5. **第一屏只放重点**：见 §4、§6。
6. **转世后**：各系统只看原来的门槛，到了就开，不讲解（`L.unlocked` 对 `st.rebirth > 0` 恒真）。**旧档**：原门槛已满足、或已经在用的系统，一律视为已解锁并已掌握（`L.migrateOnb`，幂等），老玩家的东西不会消失。

## 6. 文案规则（所有界面文字；事件正文另开一条线按这一节精简）

### 6.1 总则

1. **一屏一个主要信息块。** 先说结果，再说原因；原因放“详情”。
2. **数字是重点**：每句最多 1 个高亮数字（`<b>`，或结算卡的大字 / 颜色）；同一句里第二个数字不加粗。数字前后写清是什么（“战力 **13**”，不写“**13**”）。
3. **短句**：一句不超过 22 个字（412 宽一行约 22 字），能删的虚词都删（“了”“的话”“其实”“可以”“一下”）。不用括号套括号。
4. **不写条件说明书**：“××后开放”“还没解锁”之类的占位文字一律不写——没开的东西不出现（§2.3）。
5. **口吻**：老祖是秘书兼长辈，短、冲、带点损；不说教，不重复玩家刚看见的东西。

### 6.2 各处的上限

| 位置 | 上限 | 例 |
|---|---|---|
| 老祖讲解（阻塞） | **最多 2 句**，每句 1 个高亮数字；第二句必须是“现在点哪里” | “升了一层，战力 **19**。点【洞府】闭关，修炼翻 **2** 倍。” |
| 老祖气泡 | **1 句**（最多 30 字），1 个数字 | “行情好：灵草 ×**1.4**，现在卖。” |
| 问老祖建议 | 1 句 + 【前往】；数字 1 个 | “修为圆满，冲筑基 **100%**。” |
| 按钮 | **2～4 个字**；次要说明放按钮下方小字（最多 8 字） | 【出发】【换上】【熔炼】【开始突破】；小字“还差 23 灵石” |
| 结算卡第一屏 | 结果（印章 / 大字）+ 最重要的 **1～2 个变化**（大字或颜色） | “甲” + “灵石 **+320** · 战力 13 → **19**” |
| 面板顶部说明（sub） | **删掉，或收成一行 ≤ 20 字** | 洞府：“灵石 1283 · 修炼 +24/周天” |
| 列表行 | 名字 + 1 行效果（≤ 20 字）+ 价格按钮 | “聚灵阵 Lv3 → 修炼 +24 → +27” |
| 札记 | 1 行任务（≤ 14 字）+ 奖励 | “闭关一次 · 灵石+80” |
| 横幅 | 标题 ≤ 8 字 + 副标题 ≤ 14 字 | “新 · 坊市”“小目标：买一样东西” |

### 6.3 手机适配
