# 废柴仙途

一款像素风个人修仙游戏。被宗门逐出、被当众退婚的杂灵根废柴，捡到一枚住着老爷爷的戒指，从此一路逆袭到白日飞升。

系统极简、只靠点按，修仙的爽点一个不少：灵根觉醒、三年之约、渡劫突破、越级挑战、三宗争徒、宗门晋升、天骄榜打脸、白日飞升、转世重修。

单文件网页，打开 `dist/index.html` 即可游玩（手机、电脑都行），进度自动保存在本机。

## 怎么玩

第一次进游戏，戒中老祖会像秘书一样一步步带你：一次只说一两句，说话时游戏暂停，每句都带具体数字（“战力 10 → 13，胜算 3% → 16%”），说完立刻让你动手。坊市、宗门这些入口一开始是灰的，用得上时才解锁，老祖会在那一刻告诉你它能干什么。

修为条下面一排是**核心数值**：修炼/周天、战力、灵石/周天，最右边是**下一件大事**的倒计时——开局是“约战 N周天 · 胜算 X%”（三年之约），之后是天骄论道、九宗会武。点前三格能看到数值由哪些加成组成、怎么提升；约战前点最右边能看到双方战力和“老祖锦囊”（每条办法能把胜算提到多少），筑基且约战打完以后点开是**年历**：一条 24 格的时间轴，标着论道、拍卖会、会武、夏季秘境和当前的天下大势，各带倒计时。

一年 12 个周天分四季：春（灵田灵草 +50%、访客多三成）、夏（秘境开放、兽类地图斩妖灵石 +15%）、秋（灵田灵石 +50%、行情 +0.2）、冬（闭关倍率 +0.2，冬末论道）。每年第 2 个周天看一次天象，六成起一件**天下大势**（兽潮、灵气潮汐、丹道大会、矿脉现世、魔劫、流星雨、大旱、仙府现世、商路断绝、名师讲道、通缉令、太平无事），持续 6～10 周天，场景右上角挂一块小牌，老祖开头说一句“这几个周天该干什么”（带数字）。

三年之约（第 36 个周天开打，对手战力 125，筑基前老祖借你 2.5 倍战力）按 `tools/sim.js` 200 局模拟：只打坐胜算约 21%，懒散玩家（每届论道前出门两趟、不闭关、功法法宝只照掉落卡换、不强化）约 63%，跟着引导循环历练、闭关、升级、换克制的战技、强化兵器约 94%。

其余交给时间：打坐自动涨修为，小境界自动提升（每层战力 ×1.5）；历练途中修炼减半，所以“出门拿资源”和“在家闭关”要取舍。在洞府打坐时脚下的吐纳环会蓄满，点自己立得 1 周天修为。洞府门口有时来访客（画面里的“！”）。修为条变成金色时点它，冲击大境界（破境丹每枚 +15%，一次最多 3 枚；金丹起要渡雷劫，见下）。三年之约之后，每 12 周天举行一届天骄论道，打赢了排名飙升。底部的札记栏是本章的任务，做完即领。

**天劫**（金丹起每次突破）：基础成功率比筑基前低一截（金丹 40% … 渡劫→飞升 10%），靠**护劫手段**补回——祭法宝 +8%（失败时兵器强化 −1）、道侣护法 +8%（每境界一次，失败好感 −5）、灵宠挡劫 +10%（灵宠名册上线后可用）、渡劫阵（聚灵阵每级 +1%，阵法上线后可布）、临阵吞丹每枚 +10%（最多 2 枚，算在 3 枚之外，丹毒 +20）。准备页勾好手段、点【引动天劫】：劫云压顶，一道道雷按开渡时就掷好的结果落下，护体条一截截掉；**倒数第二道之前停一次**，老祖看一眼护体说“大概能过 / 悬 / 过不了”（八成准，红线是他估的落点），这时还能补上没用的手段。成了按余量评 完美 / 上 / 中 / 下，永久**道基**（修炼、战力）+3% / +2% / +1% / +0%，累计上限 +24%；金丹那一次定名“一品金丹”…。元婴、化神、合体的雷劫之前先过**心魔劫**：心魔翻出你这一世的旧账（第一笔因果、没选的那位道侣、陆天衡），与当初一致这一劫 +5%，动摇 −5% 但了结一笔因果；飞升前夜还有一位访客。筑基仍是一次掷。

**道心与因果**：奇遇选项带狂 / 稳 / 仁的倾向，各到 5 / 12 / 25 笔得一级——狂：越级奖励 ×2.4、对决胜算下限 8%、丁等“以伤换命”再战一次；稳：突破 +3%、闭关 −15%、天劫那一停的提示十成准；仁：来访好感多 +1、徒弟成长 +20%（徒弟上线后）、五心只要好感 90。杀、夺、负人的选项记一条**因果**（带当事人），过些日子仇家上门、途中伏击、心魔劫翻旧账，能在那时赔礼了结；轮回时每条没了的 −2% 道果（轮回殿上线时结算）。章末与飞升结局的评语按最高的那条道心写。

境界：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升。境界越高寿元越长，但一个周天流逝的年数也越多。寿元将尽时突破有绝境加成；真的坐化了就转世重修，天赋三选一，下一世更快。

按 `tools/sim.js` 的引导型玩法，第一世约 490～600 周天飞升（中位数约 558；1 倍速一周天 5 秒，可开 2 倍、4 倍速）。法宝的新东西关掉（`node tools/sim.js all 200 nogear`：只剩兵器的阶倍率）时明显更慢，功法系统关掉（`noarts`）时更慢：两者让化神以后的境界各快了一到三成。到渡劫期，强化让战力约 ×1.3、词条（锋锐、克 X）的战力当量约 ×1.15，与 `docs/SYSTEMS.md` §18 的预算一致；饰品与养气让修炼约 ×1.28，高于预算的 +12%。前期境界仍比设计目标快、后期仍偏慢；天骄榜前列的对手按法宝的预算抬高了一截（前 4 名 ×1.5）。

秘境这一刀（`norealm` 对照，已合并灵宠与天劫道心）：引导型一世进秘境约 47 次（通关约 12、离开约 35、出局几乎没有，平均走到第 5.9 层），飞升 543 → 514 周天、天骄榜第一 312 → 264 周天（秘境掉的法宝功法、秘藏与灵宠蛋；合并前秘境单独对照时飞升 603 → 607，基本持平——现在与灵宠名册、天劫道基叠起来快了约 5%，留给最后统一校准）；秘境带回的灵石约占历练的五成，出来的 3 个周天挤掉一些历练，“历练收入 : 被动收入”1.17 → 0.85。三年之约不受影响（第一世秘境要约战打完才开）：guided 93%、idle 19%。

重新打包：

```
sudo apt install android-sdk-build-tools android-sdk-platform-23 apksigner zipalign default-jdk
bash tools/build_apk.sh
```

签名文件默认是 `android/release.keystore`（不进仓库）。以后更新版本要用同一个签名文件，才能覆盖安装、保留存档。

## 开发

```

src/logic/        逻辑模块：core 参数与公式、事件能力登记 → stats 倍率汇总 → items → arts 五行与功法 → gear 法宝三槽·词条·强化·打造 → home → npc → rivals → sect → expedition
                  → cultivation 吐纳·突破（筑基的一次掷与天劫共用的结算）·闭关 → calendar 四季·固定历·天下大势 → market 货架·行情·拍卖竞价·坊市事件 → realm 秘境 → alchemy → events-engine
                  → pets 灵宠名册·岗位·进化 → quests → meta → trib 天劫（预掷、护劫手段、临场一停、评价与道基、心魔劫）→ dao 道心·因果
                  → save（存档迁移，现在 v6；没有名册的档把旧灵宠折进名册）→ tick
src/events.js     奇遇与主线事件数据（tools/check_events.js 校验）
src/content/      事件扩展包（events-engine 的 L.CONTENT_FILES 列出加载顺序，node 与 dist 都加载）；
                  事件用到的每个写法都要有系统用 L.supportFx / supportElig / supportTrigger… 登记过才会出现
src/art.js        像素美术：精灵、洞府场景、历练场景（全部代码绘制）
src/ui/           界面片段（共用一个作用域），按 tools/build.py 的 UI_PARTS 顺序拼接
src/template.html 样式与页面骨架
tools/build.py    裁剪像素字体并打包成单文件 → dist/
tools/sim.js      数值模拟：node tools/sim.js（三种策略 × 200 种子汇总）；node tools/sim.js guided 1 v 7（单局逐 12 周天）；
                  加 noarts 关掉功法系统、nogear 关掉法宝的新东西（法衣、饰品、强化、词条）、nocal 关掉四季与大势、nomarket 让 guided 不用行情拍卖轮换货、norealm 关掉秘境、nopets 关掉灵宠的等级进化岗位天赋、nodaoji 渡劫评价不给道基，
                  与默认对照量 SYSTEMS §18 的预算
tools/check_events.js 事件校验；加 report 列出上线 / 闸住的数量与闸住最多的键
tools/preview.js  美术预览：渲染 tools/preview.html 里的精灵与场景
tools/shot.js     Playwright 冒烟测试与截图
tools/longrun.js  机器人通过界面完整玩一世（功法掉落卡点【换上】、每 24 周天在功法页点“荐”；法宝对比卡更强就换、否则熔炼、偶尔锁定，
                  每 12 周天去法宝页点【强化】；每 6 周天逛坊市：处理坊市事件、卖多的破境丹、买轮换货、拍卖会出价；大势起了点小牌看年历；
                  每 12 周天进兽栏：出战最强的、空着的派岗、喂兽粮、发光的点进化、名册满时放生或替换；天劫准备页把手段全点上、心魔劫随手选、那一停补满再继续），检查全程无报错且飞升
tools/guide_test.js 按真实玩家的点法走一遍新手引导，逐步截图
tools/content_test.js 奇遇、炼丹、首领、会武、功法、法宝（对比卡、强化与保底、继承、词条、熔炼、fx.ore / fx.plus、打造、v4 → v5 迁移）、人物分页、
```

构建：

```
pip install fonttools brotli

```

## 字体

像素字体使用 TakWolf 的 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font)（SIL Open Font License 1.1，见 `tools/FONT-LICENSE.txt`）。打包时裁剪为游戏所需字符与 GB2312 一级常用字，并按 OFL 要求改名为 XPixel。
